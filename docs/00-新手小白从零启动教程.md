# 校园搭子预约系统 · 从零到运行（新手小白版）

> 本教程面向**第一次接触本项目**的同学。只要按顺序照做，就能把整个项目跑起来。
> 全程在 **Windows** 电脑上操作，命令在「PowerShell」或「CMD」里输入都可以（怎么打开见第 0 步）。

---

## 这个项目由哪几部分组成？

| 部分 | 技术 | 端口 | 作用 |
|------|------|------|------|
| 后端 `backend/` | Java + Spring Boot | **8080** | 提供所有接口（登录、发帖、报名、评价…） |
| H5 用户端 `frontend-h5/` | Vue3 + Vant（手机网页） | **3000** | 学生用的手机端 |
| 管理端 `frontend-admin/` | Vue3 + Element Plus（电脑后台） | **3001** | 管理员用的电脑端 |
| MySQL | 数据库 | 3306 | 存所有数据 |
| Redis | 缓存 | 6379 | 登录失败锁定、浏览量去重等 |

启动顺序建议：**先 Redis → 再 MySQL → 再后端 → 再前端**。

## 第 0 步：确认电脑上装好了必备软件

> 检查方法：按 `Win` 键，输入 `powershell` 回车打开 PowerShell，然后逐条输入下面的命令，**能显示出版本号**就代表这个软件装好了。

| 软件 | 最低版本 | 检查命令 |
|------|---------|---------|
| JDK | 1.8 及以上（1.8 / 11 / 17 都行） | `java -version` |
| Maven | 3.6+ | `mvn -version` |
| MySQL | 8.0 | `mysql --version` |
| Redis | 5.0 | 见下方说明 |
| Node.js | **18**（推荐 18.17+） | `node -v` |
| Git | 任意 | `git --version` |

### 没装怎么办？

- **JDK**：去官网 [oracle.com/java](https://www.oracle.com/java/technologies/downloads/) 下载，Windows x64 选 `.exe` 安装包，一路「下一步」。装完重启 PowerShell 再检查。
- **Maven**：去 [maven.apache.org](https://maven.apache.org/download.cgi) 下载 `apache-maven-3.9.x-bin.zip`，解压到 `D:\apache-maven`。然后按 `Win` 键 → 搜索「编辑系统环境变量」→「环境变量」→ 在「系统变量」的 `Path` 里**新增一行** `D:\apache-maven\bin`，点确定。重开 PowerShell 再 `mvn -version`。
- **MySQL**：去 [dev.mysql.com/downloads/installer](https://dev.mysql.com/downloads/installer/) 下载 **MySQL Installer**，按向导安装，其中一步会让你**设置 root 密码**——请牢牢记住这个密码（后面要用）。
- **Node.js**：去 [nodejs.org](https://nodejs.org/) 下载 **LTS 版本**，`.msi` 安装包一路「下一步」。Node 装好会自带 npm。
- **Git**：去 [git-scm.com](https://git-scm.com/) 下载安装，一路默认即可。
- **Redis**：Redis 官方不支持 Windows，推荐下载社区维护的 Windows 版：
  1. 打开 [github.com/tporadowski/redis/releases](https://github.com/tporadowski/redis/releases)
  2. 下载 `Redis-x64-5.0.14.1.zip`
  3. 解压到 `D:\redis`
  4. 之后每次启动，双击里面的 `redis-server.exe` 即可（第 4 步会细说）

## 第 1 步：把代码拿到本地

在你选好的目录（比如 `D:\Code`）里，打开 PowerShell 并执行：

```powershell
cd D:\Code
git clone 你的仓库地址 school-buddy-system-gyy
cd school-buddy-system-gyy
```

如果项目已经在你自己电脑上（不是 clone 的），直接跳过这一步。

> 💡 项目最终结构应该是这样：
> ```
> school-buddy-system-gyy/
> ├─ backend/          # 后端
> ├─ frontend-h5/      # H5 用户端
> ├─ frontend-admin/   # 管理端
> ├─ database/         # 数据库脚本
> └─ docs/             # 文档
> ```

## 第 2 步：创建本地配置文件（⚠️ 最重要，漏了后端启动不起来）

项目为了安全，**没有把数据库密码和 JWT 密钥写进仓库**，它们放在一个被 `.gitignore` 忽略的文件里，需要你自己创建。

1. 进入 `backend/src/main/resources/` 目录
2. 找到 **`application-local.example.yml`** 这个文件
3. **把它复制一份，改名为 `application-local.yml`**
   - 在文件管理器里：复制粘贴，然后重命名
   - 或 PowerShell：`Copy-Item application-local.example.yml application-local.yml`
4. 用记事本打开 `application-local.yml`，改成你自己的值：

```yaml
spring:
  datasource:
    password: 你的MySQL密码        # ← 改成第 0 步安装 MySQL 时设置的 root 密码

jwt:
  secret: 一串足够长的随机字符串     # ← 建议 >= 32 个字符，随便打一些字母数字
```

保存。这个文件**不会被提交到 git**（已在 `.gitignore` 里），所以你的密码不会泄露。

> ⚠️ 如果你的 MySQL root 密码恰好是 `1234`，文件里已经填好了，可以直接用。

## 第 3 步：创建数据库并导入数据

1. **先启动 MySQL**：
   - 如果你装的是 MySQL Installer，Windows 服务里一般已经自动启动了
   - 确认方式：PowerShell 输入 `mysql -u root -p`，输入密码能进到 `mysql>` 提示符就代表启动成功

2. **创建数据库**（在 `mysql>` 提示符下输入，然后退出）：

```sql
CREATE DATABASE IF NOT EXISTS school_buddy DEFAULT CHARACTER SET utf8mb4;
EXIT;
```

3. **导入表结构和数据**（回到 PowerShell，在**项目根目录**执行）：

```powershell
cd D:\Code\school-buddy-system-gyy
mysql -u root -p < database\schema.sql
mysql -u root -p < database\test-data.sql
mysql -u root -p < database\test-data-more.sql
```

- `schema.sql`：建表 + 基础账号（管理员、几个学生、兴趣标签）
- `test-data.sql` / `test-data-more.sql`：更丰富的测试数据（帖子、报名、评价等），导入后广场上就有内容可看

每行输入密码时如果没有反应是正常的（密码不显示），输完回车即可。

## 第 4 步：启动 Redis

找到第 0 步解压的 `redis-server.exe`，**双击运行**。看到类似下面的输出就说明启动成功（这个窗口先别关）：

```
[XXXXX] Ready to accept connections tcp
```

> ⚠️ 后端强依赖 Redis（登录锁定、浏览量去重），**Redis 没启动，后端登录功能会不可用**。

---

## 第 5 步：启动后端

1. 打开 PowerShell，进入 backend 目录，**第一次要下载依赖**（耐心等待，可能要几分钟）：

```powershell
cd D:\Code\school-buddy-system-gyy\backend
mvn clean install -DskipTests
```

2. 启动后端：

```powershell
mvn spring-boot:run
```

3. 看到下面这行就说明启动成功了（**这个窗口先别关**）：

```
Started BuddyApplication in X.XX seconds
```

> 常见问题：如果报错说找不到数据库/连接被拒，多半是 **第 2 步的密码填错** 或 **第 3 步数据库没导入**。

## 第 6 步：启动 H5 用户端（学生手机端）

新开一个 PowerShell，执行：

```powershell
cd D:\Code\school-buddy-system-gyy\frontend-h5
npm install
npm run dev
```

- 第一次 `npm install` 要下载依赖，会比较慢。如果卡住，可以先配置国内镜像再重试：
  ```powershell
  npm config set registry https://registry.npmmirror.com
  ```
- 看到 `Local: http://localhost:3000/` 就成功了。**在浏览器打开 `http://localhost:3000`**（按 F12 → 设备图标可以模拟手机效果）。

## 第 9 步：常见问题（FAQ）

**Q1：后端报 `Failed to configure a DataSource` 或 `Access denied for user`**
答：数据库密码错了或没填。检查 `backend/src/main/resources/application-local.yml` 里的 `password` 是否和 MySQL root 密码一致。

**Q2：报错提示找不到 `application-local.yml` / `JWT_SECRET` 为空**
答：请按**第 2 步**复制 `application-local.example.yml` 为 `application-local.yml` 并填好值。

**Q3：`mvn` 不是内部或外部命令**
答：Maven 没装好或没配环境变量。见第 0 步 Maven 安装说明，装完**重开** PowerShell。

**Q4：`node` / `npm` 不是内部或外部命令**
答：Node.js 没装或没配 Path。重装 Node.js 后**重开** PowerShell。

**Q5：`npm install` 很慢或卡住不动**
答：先配置国内镜像：`npm config set registry https://registry.npmmirror.com`，再重新 `npm install`。

**Q6：后端起来后登录报「系统繁忙」或「无法连接 Redis」**
答：Redis 没启动。双击 `redis-server.exe` 后再试（第 4 步）。

**Q7：`mysql` 不是内部或外部命令**
答：MySQL 的 `bin` 目录没加进环境变量 Path，或者你用的是图形化工具。可以改用 Navicat / DataGrip 等工具执行 `database/` 下的 SQL 脚本。

**Q8：导入 SQL 报错 `Unknown database 'school_buddy'`**
答：忘了先执行 `CREATE DATABASE school_buddy ...`。回到第 3 步第 2 小步。

**Q9：前端页面打开是空白 / 请求 404**
答：确认后端已启动（8080 有服务）；确认前端是通过 `npm run dev` 启动的（不是直接双击 html）；确认 URL 端口是 3000 / 3001。

**Q10：`端口被占用`（Port 8080/3000/3001 already in use）**
答：可能是之前没关干净。关掉占用端口的窗口；或用命令查找并结束进程：`netstat -ano | findstr 8080`，然后用 `taskkill /PID 进程号 /F`。

**Q11：改了代码没生效？**
答：后端改 Java 代码需要**重启** `mvn spring-boot:run`；前端改代码保存后 Vite 会自动刷新，一般不用重启。

**Q12：H5 点「报名」后一直转圈 / 报「登录已过期」**
答：说明你还没登录。回到 H5 首页点「我的」→ 登录后再操作。

## 附录 B：以后每次怎么快速启动？

以后不用再装软件了，按顺序启动即可：

1. 双击 `redis-server.exe`（或开机自启）
2. 确认 MySQL 服务在运行（Windows 服务里 MySQL 一般自动启动）
3. 后端：`cd backend && mvn spring-boot:run`
4. H5：`cd frontend-h5 && npm run dev`
5. 管理端：`cd frontend-admin && npm run dev`
