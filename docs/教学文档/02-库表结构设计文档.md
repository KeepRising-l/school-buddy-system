## 一、设计原则

### 1.1 总体原则

| 原则 | 说明 |
|------|------|
| 命名规范 | 表名小写下划线分隔，字段名小写下划线分隔；关联表格式 `主表_从表` |
| 主键设计 | 所有表使用 BIGINT 自增主键，避免 UUID 带来的索引性能问题 |
| 时间字段 | 统一使用 `created_time` / `updated_time`，DATETIME 类型，`updated_time` 自动更新 |
| 软删除 | 核心业务表（帖子、用户）采用状态字段标记，不做物理删除；评论等辅助表可物理删除 |
| 状态字段 | 使用 VARCHAR 枚举字符串（如 'RECRUITING'）而非数字，提升可读性 |
| 索引策略 | 在外键字段、查询频繁的字段上建立索引；联合索引遵循最左前缀原则 |
| 冗余控制 | 适度冗余（如帖子表中存 current_people），避免频繁 JOIN 统计 |

### 1.2 字段类型规范

| 数据类型 | 适用场景 | 示例 |
|---------|---------|------|
| BIGINT | 主键、外键、ID 字段 | id, user_id, post_id |
| VARCHAR | 变长字符串 | nickname, title, status |
| TEXT | 长文本 | description, content |
| TINYINT | 小范围整数/布尔 | gender, is_admin, status |
| INT | 普通整数 | credit_score, max_people |
| DATETIME | 日期时间 | start_time, created_time |
| DECIMAL | 精确小数（本系统暂未使用） | - |

## 二、运营视角的配置诉求

### 2.1 运营场景分析

管理员（运营人员）需要通过后台对平台进行配置和管理，核心配置诉求如下：

| 配置诉求 | 对应表 | 配置方式 | 说明 |
|---------|--------|---------|------|
| 管理兴趣分类和标签 | `interest_tag` | 后台 CRUD | 运营可新增分类（如"剧本杀"）、新增标签、调整排序、禁用过时标签 |
| 审核用户身份 | `sys_user` | 后台审核 | 运营查看用户信息，封禁违规用户 |
| 审核帖子内容 | `post.is_audit_pass` | 后台审核 | 运营下架违规/广告帖 |
| 处理信誉纠纷 | `sys_user.credit_score` | 后台手动调整 | 运营可重置用户信誉分 |
| 查看运营数据 | 多表聚合统计 | 后台报表 | 统计发帖量、组局数、活跃用户 |

### 2.2 运营配置字段设计

#### 2.2.1 标签管理配置

```sql
-- interest_tag 表中的运营配置字段
category     -- 分类名称，运营可自定义新增
name         -- 标签名称
description  -- 标签描述（运营填写，帮助用户理解）
sort_order   -- 排序权重（运营控制展示顺序）
status       -- 启用/禁用（运营控制标签上下架）
```

#### 2.2.2 帖子审核配置

```sql
-- post 表中的运营配置字段
is_audit_pass  -- 审核状态：1通过 0待审
-- 运营可配置：是否开启发帖审核（若关闭则发帖默认通过）
```

#### 2.2.3 用户管控配置

```sql
-- sys_user 表中的运营配置字段
status       -- 用户状态：1正常 0封禁（运营封禁违规用户）
is_admin     -- 是否管理员（运营分配管理员权限）
credit_score -- 信誉分（运营可手动调整，处理纠纷）
```

### 2.3 运营统计诉求

| 统计指标 | 数据来源 | 统计方式 |
|---------|---------|---------|
| 每日发帖量 | `post.created_time` | 按日期分组 COUNT |
| 成功组局数 | `post.status = 'FINISHED'` | 按日期分组 COUNT |
| 活跃用户数 | `post` + `post_apply` + `review` | 按日期去重 COUNT user_id |
| 热门分类 Top5 | `post.category` | 按分类分组 COUNT 排序 |
| 信誉分分布 | `sys_user.credit_score` | 按区间分组 COUNT |
| 用户增长趋势 | `sys_user.created_time` | 按日期累计 COUNT |

## 三、用户视角的使用诉求

### 3.1 学生用户场景分析

| 使用场景 | 涉及表 | 核心字段 | 说明 |
|---------|--------|---------|------|
| 注册并完善资料 | `sys_user` | student_no, phone, nickname, avatar, college | 用户填写个人信息 |
| 设置兴趣和段位 | `user_tag`, `interest_tag` | tag_id, self_level | 用户选择感兴趣的项目并自评段位 |
| 发布组局 | `post` | title, category, start_time, location, max_people | 用户创建活动招募帖 |
| 浏览广场找搭子 | `post` + `sys_user` | status, current_people, credit_score | 用户查看招募中的帖子 |
| 报名参加活动 | `post_apply` | post_id, applicant_id, status | 用户申请加入组局 |
| 管理报名申请 | `post_apply` | status, handle_time | 发布者审核报名申请 |
| 活动后互评 | `review` | rating, tag, content | 用户对搭子进行评价 |
| 查看信誉分 | `sys_user` | credit_score | 用户查看自己的信誉星级 |
| 发表评论 | `post_comment` | content | 用户在帖子下评论交流 |

### 3.2 用户数据流视角

```
用户注册 → sys_user（写入用户基本信息）
    ↓
设置标签 → user_tag（关联用户与兴趣标签）
    ↓
发布组局 → post（创建帖子）+ post.current_people = 1（发布者占位）
    ↓
他人报名 → post_apply（写入报名记录，status=PENDING）
    ↓
发布者审核 → post_apply.status = APPROVED + post.current_people + 1
    ↓
满员 → post.status = FULL
    ↓
活动开始 → post.status = ONGOING
    ↓
活动结束 → post.status = FINISHED
    ↓
互评 → review（写入评价记录）
    ↓
信誉更新 → sys_user.credit_score（定时任务重新计算）
```

## 五、详细表结构设计

### 5.1 sys_user（用户表）

**表说明**：存储平台所有用户信息，包括学生用户和管理员。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|---------|--------|--------|------|
| id | BIGINT | NOT NULL | AUTO_INCREMENT | 主键 |
| student_no | VARCHAR(32) | NOT NULL | - | 学号 |
| phone | VARCHAR(16) | NULL | NULL | 手机号 |
| password | VARCHAR(128) | NOT NULL | - | 密码（BCrypt 加密） |
| nickname | VARCHAR(64) | NULL | NULL | 昵称 |
| avatar | VARCHAR(255) | NULL | NULL | 头像 URL |
| signature | VARCHAR(255) | NULL | NULL | 个性签名 |
| college | VARCHAR(128) | NULL | NULL | 所属学院 |
| gender | TINYINT | NULL | 0 | 性别：0未知 1男 2女 |
| credit_score | INT | NOT NULL | 100 | 信誉分（0-100） |
| status | TINYINT | NOT NULL | 1 | 状态：1正常 0封禁 |
| is_admin | TINYINT | NOT NULL | 0 | 是否管理员：0否 1是 |
| created_time | DATETIME | NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_time | DATETIME | NULL | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| PRIMARY | 主键 | id | 主键索引 |
| uk_student_no | 唯一 | student_no | 学号唯一，防重复注册 |
| uk_phone | 唯一 | phone | 手机号唯一 |

**建表 SQL**：

```sql
CREATE TABLE `sys_user` (
    `id`           BIGINT        NOT NULL AUTO_INCREMENT COMMENT '主键',
    `student_no`   VARCHAR(32)   NOT NULL                   COMMENT '学号',
    `phone`        VARCHAR(16)   DEFAULT NULL               COMMENT '手机号',
    `password`     VARCHAR(128)  NOT NULL                   COMMENT '密码(BCrypt)',
    `nickname`     VARCHAR(64)   DEFAULT NULL               COMMENT '昵称',
    `avatar`       VARCHAR(255)  DEFAULT NULL               COMMENT '头像URL',
    `signature`    VARCHAR(255)  DEFAULT NULL               COMMENT '个性签名',
    `college`      VARCHAR(128)  DEFAULT NULL               COMMENT '所属学院',
    `gender`       TINYINT       DEFAULT 0                  COMMENT '性别 0未知 1男 2女',
    `credit_score` INT           DEFAULT 100                COMMENT '信誉分 0-100',
    `status`       TINYINT       DEFAULT 1                  COMMENT '状态 1正常 0封禁',
    `is_admin`     TINYINT       DEFAULT 0                  COMMENT '是否管理员 0否 1是',
    `created_time` DATETIME      DEFAULT CURRENT_TIMESTAMP,
    `updated_time` DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_student_no` (`student_no`),
    UNIQUE KEY `uk_phone` (`phone`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 5.2 interest_tag（兴趣标签表）

**表说明**：存储系统预设的兴趣分类和项目标签，由管理员维护。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|---------|--------|--------|------|
| id | BIGINT | NOT NULL | AUTO_INCREMENT | 主键 |
| category | VARCHAR(64) | NOT NULL | - | 分类名称（球类/电竞/桌游/跑步） |
| name | VARCHAR(64) | NOT NULL | - | 项目名称（篮球/羽毛球/王者荣耀） |
| description | VARCHAR(255) | NULL | NULL | 标签描述 |
| sort_order | INT | NULL | 0 | 排序权重（升序） |
| status | TINYINT | NULL | 1 | 状态：1启用 0禁用 |
| created_time | DATETIME | NULL | CURRENT_TIMESTAMP | 创建时间 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| PRIMARY | 主键 | id | 主键索引 |
| idx_category | 普通 | category | 按分类查询标签 |

**建表 SQL**：

```sql
CREATE TABLE `interest_tag` (
    `id`           BIGINT        NOT NULL AUTO_INCREMENT,
    `category`     VARCHAR(64)   NOT NULL        COMMENT '分类，如 篮球/羽毛球/王者荣耀',
    `name`         VARCHAR(64)   NOT NULL        COMMENT '项目名',
    `description`  VARCHAR(255)  DEFAULT NULL,
    `sort_order`   INT           DEFAULT 0,
    `status`       TINYINT       DEFAULT 1       COMMENT '1启用 0禁用',
    `created_time` DATETIME      DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    KEY `idx_category` (`category`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='兴趣标签表';
```

### 5.3 user_tag（用户-标签关联表）

**表说明**：存储用户选择的兴趣标签及自评段位。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|---------|--------|--------|------|
| id | BIGINT | NOT NULL | AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL | - | 用户 ID |
| tag_id | BIGINT | NOT NULL | - | 标签 ID |
| self_level | INT | NULL | 1 | 自评段位：1青铜 2白银 3黄金 4钻石 5王者 |
| created_time | DATETIME | NULL | CURRENT_TIMESTAMP | 创建时间 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| PRIMARY | 主键 | id | 主键索引 |
| uk_user_tag | 唯一 | (user_id, tag_id) | 防止用户重复选择同一标签 |

**建表 SQL**：

```sql
CREATE TABLE `user_tag` (
    `id`           BIGINT   NOT NULL AUTO_INCREMENT,
    `user_id`      BIGINT   NOT NULL,
    `tag_id`       BIGINT   NOT NULL,
    `self_level`   INT      DEFAULT 1         COMMENT '自评段位 1-5',

    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_tag` (`user_id`, `tag_id`)

```

### 5.4 post（组局帖子表）

**表说明**：存储所有组局帖子信息，是系统的核心业务表。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|---------|--------|--------|------|
| id | BIGINT | NOT NULL | AUTO_INCREMENT | 主键 |
| publisher_id | BIGINT | NOT NULL | - | 发布者用户 ID |
| title | VARCHAR(128) | NOT NULL | - | 帖子标题 |
| category | VARCHAR(64) | NOT NULL | - | 所属分类 |
| tag_ids | VARCHAR(255) | NULL | NULL | 相关标签 ID 列表（逗号分隔） |
| start_time | DATETIME | NOT NULL | - | 活动开始时间 |
| end_time | DATETIME | NOT NULL | - | 活动结束时间 |
| location | VARCHAR(128) | NOT NULL | - | 活动地点 |
| max_people | INT | NOT NULL | 2 | 最大人数 |
| current_people | INT | NOT NULL | 1 | 当前人数（含发布者） |
| require_level | INT | NULL | NULL | 要求最低段位（NULL 不限） |
| require_gender | TINYINT | NULL | 0 | 要求性别：0不限 1男 2女 |
| description | TEXT | NULL | NULL | 详细描述 |
| status | VARCHAR(24) | NOT NULL | 'RECRUITING' | 帖子状态 |
| view_count | INT | NULL | 0 | 浏览次数 |
| like_count | INT | NULL | 0 | 点赞次数 |
| is_audit_pass | TINYINT | NULL | 1 | 审核状态：1通过 0待审 |
| created_time | DATETIME | NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_time | DATETIME | NULL | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| PRIMARY | 主键 | id | 主键索引 |
| idx_publisher | 普通 | publisher_id | 查询用户发布的帖子 |
| idx_status_time | 联合 | (status, start_time) | 广场查询：按状态+时间筛选排序 |

**建表 SQL**：

```sql
CREATE TABLE `post` (
    `id`             BIGINT        NOT NULL AUTO_INCREMENT,
    `publisher_id`   BIGINT        NOT NULL             COMMENT '发布人',
    `title`          VARCHAR(128)  NOT NULL,
    `category`       VARCHAR(64)   NOT NULL             COMMENT '所属分类',
    `tag_ids`        VARCHAR(255)  DEFAULT NULL         COMMENT '相关标签id列表，逗号分隔',
    `start_time`     DATETIME      NOT NULL,
    `end_time`       DATETIME      NOT NULL,
    `location`       VARCHAR(128)  NOT NULL             COMMENT '活动地点',
    `max_people`     INT           NOT NULL DEFAULT 2   COMMENT '最大人数',
    `current_people` INT           NOT NULL DEFAULT 1   COMMENT '当前人数(含发布者)',
    `require_level`  INT           DEFAULT NULL         COMMENT '要求最低段位，空则不限',
    `require_gender` TINYINT       DEFAULT 0             COMMENT '0不限 1男 2女',
    `description`    TEXT,
    `status`         VARCHAR(24)   NOT NULL DEFAULT 'RECRUITING',
    `view_count`     INT           DEFAULT 0,
    `like_count`     INT           DEFAULT 0,
    `is_audit_pass`  TINYINT       DEFAULT 1             COMMENT '管理员是否已审核通过 1通过 0待审',
    `created_time`   DATETIME      DEFAULT CURRENT_TIMESTAMP,
    `updated_time`   DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    KEY `idx_publisher` (`publisher_id`),
    KEY `idx_status_time` (`status`, `start_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='组局帖子表';
```

### 5.5 post_apply（报名表）

**表说明**：存储用户报名组局的记录，驱动预约履约流程。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|---------|--------|--------|------|
| id | BIGINT | NOT NULL | AUTO_INCREMENT | 主键 |
| post_id | BIGINT | NOT NULL | - | 帖子 ID |
| applicant_id | BIGINT | NOT NULL | - | 报名者用户 ID |
| status | VARCHAR(24) | NOT NULL | 'PENDING' | 报名状态 |
| apply_time | DATETIME | NULL | CURRENT_TIMESTAMP | 报名时间 |
| handle_time | DATETIME | NULL | NULL | 处理时间（审核时间） |
| remark | VARCHAR(255) | NULL | NULL | 备注 |

**报名状态枚举**：

| 状态值 | 说明 |
|--------|------|
| PENDING | 待审核 |
| APPROVED | 已加入（发布者同意） |
| REJECTED | 已拒绝（发布者拒绝） |
| CANCELLED | 已退出（报名者取消） |
| ATTENDED | 已参加（活动结束后标记） |
| NOSHOW | 爽约（活动结束后标记） |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| PRIMARY | 主键 | id | 主键索引 |
| uk_post_applicant | 唯一 | (post_id, applicant_id) | 防止重复报名 |
| idx_applicant | 普通 | applicant_id | 查询用户报名记录 |

**建表 SQL**：

```sql
CREATE TABLE `post_apply` (
    `id`           BIGINT        NOT NULL AUTO_INCREMENT,
    `post_id`      BIGINT        NOT NULL,
    `applicant_id` BIGINT        NOT NULL,
    `status`       VARCHAR(24)   NOT NULL DEFAULT 'PENDING',
    `apply_time`   DATETIME      DEFAULT CURRENT_TIMESTAMP,
    `handle_time`  DATETIME      DEFAULT NULL,
    `remark`       VARCHAR(255)  DEFAULT NULL,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_post_applicant` (`post_id`, `applicant_id`),
    KEY `idx_applicant` (`applicant_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='报名表';
```

### 5.6 review（评价表）

**表说明**：存储活动结束后用户之间的互评记录。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|---------|--------|--------|------|
| id | BIGINT | NOT NULL | AUTO_INCREMENT | 主键 |
| post_id | BIGINT | NOT NULL | - | 帖子 ID |
| reviewer_id | BIGINT | NOT NULL | - | 评价人 ID |
| target_user_id | BIGINT | NOT NULL | - | 被评价人 ID |
| rating | TINYINT | NOT NULL | - | 星级（1-5） |
| tag | VARCHAR(32) | NULL | NULL | 评价标签（靠谱/爽约/迟到） |
| content | VARCHAR(500) | NULL | NULL | 文字评价 |
| created_time | DATETIME | NULL | CURRENT_TIMESTAMP | 创建时间 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| PRIMARY | 主键 | id | 主键索引 |
| uk_post_reviewer_target | 唯一 | (post_id, reviewer_id, target_user_id) | 防止重复评价 |
| idx_target | 普通 | target_user_id | 查询用户收到的评价（计算信誉分） |

**建表 SQL**：

```sql
CREATE TABLE `review` (
    `id`             BIGINT        NOT NULL AUTO_INCREMENT,
    `post_id`        BIGINT        NOT NULL           COMMENT '帖子ID',
    `reviewer_id`    BIGINT        NOT NULL           COMMENT '评价人',
    `target_user_id` BIGINT        NOT NULL           COMMENT '被评价人',
    `rating`         TINYINT       NOT NULL           COMMENT '1-5 星',
    `tag`            VARCHAR(32)   DEFAULT NULL       COMMENT '靠谱/爽约/迟到',
    `content`        VARCHAR(500)  DEFAULT NULL,
    `created_time`   DATETIME      DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_post_reviewer_target` (`post_id`, `reviewer_id`, `target_user_id`),
    KEY `idx_target` (`target_user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='评价表';
```
