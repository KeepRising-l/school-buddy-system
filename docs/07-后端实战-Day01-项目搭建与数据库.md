1. 用 Spring Initializr 创建 Spring Boot 项目
2. 配置 pom.xml 依赖（MyBatis-Plus、JWT、Hutool 等）
3. 编写 application.yml 和 application-dev.yml 配置
4. 创建数据库 school_buddy 及 7 张表
5. 搭建项目包结构
6. 创建启动类并验证项目能跑起来

## 第一步：用 Spring Initializr 创建项目

### 操作

1. 打开浏览器，访问 [https://start.spring.io/](https://start.spring.io/)
2. 按以下选项配置：

| 配置项 | 值 |
|--------|------|
| Project | Maven |
| Language | Java |
| Spring Boot | 2.7.18 |
| Group | com.buddy |
| Artifact | school-buddy-backend |
| Name | school-buddy-backend |
| Package name | com.buddy |
| Packaging | Jar |
| Java | 8 |

3. 点击 **ADD DEPENDENCIES**，添加以下依赖：
   - **Spring Web** — 提供 RESTful API 能力
   - **Spring Security** — 安全框架（后续用自定义 JWT 拦截器替代默认认证）
   - **Spring Data Redis** — Redis 缓存支持
   - **Validation** — 参数校验（@NotBlank、@Size 等）
   - **MySQL Driver** — MySQL 数据库驱动
   - **Lombok** — 简化实体类代码

4. 点击 **GENERATE** 下载项目压缩包
5. 解压到你的工作目录，用 IDEA 打开

### 解释

- **为什么选 Spring Boot 2.7.18？** 这是 2.x 的最终版本，稳定且兼容 Java 8，社区资料丰富
- **为什么选 Java 8？** Java 8 是目前企业最广泛使用的版本，学习成本低
- **为什么一开始就加 Spring Security？** 后面做 JWT 认证需要关闭 Security 的默认行为，提前引入避免后续冲突

## 第二步：配置 pom.xml 添加额外依赖

Spring Initializr 只生成了基础依赖，我们还需要 MyBatis-Plus、JWT、Hutool 等工具库。

### 创建文件

`pom.xml`（项目根目录下，覆盖原有内容）

### 写入代码

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>2.7.18</version>
        <relativePath/>
    </parent>

    <groupId>com.buddy</groupId>
    <artifactId>school-buddy-backend</artifactId>
    <version>1.0.0</version>
    <name>school-buddy-backend</name>
    <description>校园搭子系统后端</description>

    <properties>
        <java.version>1.8</java.version>
        <mybatis-plus.version>3.5.5</mybatis-plus.version>
        <jjwt.version>0.11.5</jjwt.version>
        <hutool.version>5.8.25</hutool.version>
        <mysql-connector.version>8.0.33</mysql-connector.version>
    </properties>

    <dependencies>
        <!-- Spring Boot Web：提供 RESTful API 能力 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

        <!-- Spring Security：安全框架，后续用自定义 JWT 拦截器替代默认认证 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-security</artifactId>
        </dependency>

        <!-- Redis：缓存支持，用于验证码、Token 黑名单等 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-data-redis</artifactId>
        </dependency>

        <!-- 参数校验：@NotBlank、@Size 等注解 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-validation</artifactId>
        </dependency>

        <!-- MyBatis-Plus：MyBatis 增强工具，简化 CRUD -->
        <dependency>
            <groupId>com.baomidou</groupId>
            <artifactId>mybatis-plus-boot-starter</artifactId>
            <version>${mybatis-plus.version}</version>
        </dependency>

        <!-- MySQL 驱动：连接 MySQL 数据库 -->
        <dependency>
            <groupId>com.mysql</groupId>
            <artifactId>mysql-connector-j</artifactId>
            <version>${mysql-connector.version}</version>
            <scope>runtime</scope>
        </dependency>

        <!-- Lombok：自动生成 getter/setter/构造方法等 -->
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <optional>true</optional>
        </dependency>

        <!-- JWT：JSON Web Token，用于无状态认证 -->
        <dependency>
            <groupId>io.jsonwebtoken</groupId>
            <artifactId>jjwt-api</artifactId>
            <version>${jjwt.version}</version>
        </dependency>
        <dependency>
            <groupId>io.jsonwebtoken</groupId>
            <artifactId>jjwt-impl</artifactId>
            <version>${jjwt.version}</version>
            <scope>runtime</scope>
        </dependency>
        <dependency>
            <groupId>io.jsonwebtoken</groupId>
            <artifactId>jjwt-jackson</artifactId>
            <version>${jjwt.version}</version>
            <scope>runtime</scope>
        </dependency>

        <!-- Hutool：Java 工具类库，提供各种便捷方法 -->
        <dependency>
            <groupId>cn.hutool</groupId>
            <artifactId>hutool-all</artifactId>
            <version>${hutool.version}</version>
        </dependency>

        <!-- 测试 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
                <configuration>
                    <excludes>
                        <exclude>
                            <groupId>org.projectlombok</groupId>
                            <artifactId>lombok</artifactId>
                        </exclude>
                    </excludes>
                </configuration>
            </plugin>
        </plugins>
    </build>

</project>
```

### 解释

- **MyBatis-Plus 3.5.5**：MyBatis 的增强工具，自带通用 CRUD、分页插件、代码生成器等，比原生 MyBatis 少写 90% 的 SQL
- **jjwt 0.11.5**：分三个包引入——`jjwt-api` 是接口定义（编译时需要），`jjwt-impl` 是实现（运行时需要），`jjwt-jackson` 是 JSON 序列化支持（运行时需要）
- **Hutool 5.8.25**：国产工具类库，包含字符串处理、加密、HTTP 客户端等，避免重复造轮子
- **mysql-connector-j 8.0.33**：MySQL 8.x 的官方驱动，注意 groupId 从 `mysql` 改成了 `com.mysql`

## 第三步：配置 application.yml

我们采用多环境配置：`application.yml` 放通用配置，`application-dev.yml` 放开发环境配置（数据库密码等敏感信息）。

### 创建文件

`src/main/resources/application.yml`

### 写入代码

```yaml
server:
  port: 8080

spring:
  profiles:
    active: dev
  # Jackson 配置
  jackson:
    date-format: yyyy-MM-dd HH:mm:ss
    time-zone: GMT+8
    default-property-inclusion: non_null

# MyBatis-Plus 配置
mybatis-plus:
  mapper-locations: classpath*:/mapper/**/*.xml
  type-aliases-package: com.buddy.entity
  configuration:
    # 下划线转驼峰：数据库字段 student_no 自动映射到 Java 属性 studentNo
    map-underscore-to-camel-case: true
    # 日志输出：开发时打印 SQL，方便调试
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
  global-config:
    db-config:
      # 主键策略：数据库自增
      id-type: auto

# JWT 配置
jwt:
  secret: BuddySchoolSecretKey2024ForJwtTokenGenerationAndValidation
  # Token 过期时间：7天（毫秒）
  expiration: 604800000
```

### 解释

- **jackson.date-format**：全局设置日期格式，前端看到的日期就是 `2024-01-15 14:30:00` 而不是时间戳
- **jackson.default-property-inclusion: non_null**：JSON 返回时自动忽略 null 字段，减少数据传输量
- **map-underscore-to-camel-case: true**：这是 MyBatis-Plus 的核心配置，数据库的 `student_no` 自动映射到 Java 的 `studentNo`，不用手动写映射
- **jwt.secret**：JWT 签名密钥，必须足够长（至少 256 位），否则 HMAC-SHA 算法会报错
- **jwt.expiration**：604800000 毫秒 = 7 天，Token 有效期

### 创建文件

`src/main/resources/application-dev.yml`

### 写入代码

```yaml
# 开发环境配置
spring:
  # MySQL 数据源
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/school_buddy?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: 1234

  # Redis 配置
  redis:
    host: localhost
    port: 6379
    database: 0
    timeout: 5000ms
    lettuce:
      pool:
        max-active: 8
        max-idle: 8
        min-idle: 0
        max-wait: -1ms

# 文件上传配置
file:
  # 上传文件存储路径
  upload-path: ./uploads/
  # 允许的文件类型
  allowed-extensions: jpg,jpeg,png,gif,pdf,doc,docx,xls,xlsx
  # 最大文件大小（10MB）
  max-size: 10485760
```

### 解释

- **allowPublicKeyRetrieval=true**：MySQL 8.0 默认使用 `caching_sha2_password` 认证插件，需要允许公钥检索才能连接
- **useSSL=false**：本地开发不需要 SSL 加密连接
- **lettuce**：Spring Boot 2.x 默认的 Redis 连接客户端，比 Jedis 更高效（基于 Netty，线程安全）
- **max-active: 8**：连接池最大连接数 8，本地开发足够了

## 第四步：创建数据库和表

### 操作

打开 MySQL 客户端（Navicat、DataGrip 或命令行），执行以下 SQL。

### 创建文件

`database/schema.sql`

### 写入代码

```sql
-- =====================================================
-- 校园兴趣搭子预约系统 - 数据库脚本
-- 数据库: MySQL 8.0+  (CREATE DATABASE school_buddy DEFAULT CHARSET utf8mb4)
-- =====================================================

-- 第一步：创建数据库
CREATE DATABASE IF NOT EXISTS school_buddy DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_general_ci;

USE school_buddy;

-- -----------------------------------------------------
-- 1. 用户表
-- 存储系统所有用户信息，包括普通用户和管理员
-- -----------------------------------------------------
DROP TABLE IF EXISTS `sys_user`;
CREATE TABLE `sys_user` (
    `id`           BIGINT        NOT NULL AUTO_INCREMENT COMMENT '主键',
    `student_no`   VARCHAR(32)   NOT NULL                   COMMENT '学号，唯一标识',
    `phone`        VARCHAR(16)   DEFAULT NULL               COMMENT '手机号，可选绑定',
    `password`     VARCHAR(128)  NOT NULL                   COMMENT '密码(BCrypt加密存储)',
    `nickname`     VARCHAR(64)   DEFAULT NULL               COMMENT '昵称，展示名',
    `avatar`       VARCHAR(255)  DEFAULT NULL               COMMENT '头像URL',
    `signature`    VARCHAR(255)  DEFAULT NULL               COMMENT '个性签名',
    `college`      VARCHAR(128)  DEFAULT NULL               COMMENT '所属学院',
    `gender`       TINYINT       DEFAULT 0                  COMMENT '性别 0未知 1男 2女',
    `credit_score` INT           DEFAULT 100                COMMENT '信誉分 0-100，初始100',
    `status`       TINYINT       DEFAULT 1                  COMMENT '状态 1正常 0封禁',
    `is_admin`     TINYINT       DEFAULT 0                  COMMENT '是否管理员 0否 1是',
    `created_time` DATETIME      DEFAULT CURRENT_TIMESTAMP  COMMENT '创建时间',
    `updated_time` DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_student_no` (`student_no`),
    UNIQUE KEY `uk_phone` (`phone`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

-- -----------------------------------------------------
-- 2. 兴趣标签表（由管理员维护）
-- category: 分类，如 球类/电竞/桌游/跑步
-- -----------------------------------------------------
DROP TABLE IF EXISTS `interest_tag`;
CREATE TABLE `interest_tag` (
    `id`           BIGINT        NOT NULL AUTO_INCREMENT COMMENT '主键',
    `category`     VARCHAR(64)   NOT NULL        COMMENT '分类，如 球类/电竞/桌游/跑步',
    `name`         VARCHAR(64)   NOT NULL        COMMENT '项目名，如 篮球/王者荣耀',
    `description`  VARCHAR(255)  DEFAULT NULL    COMMENT '标签描述',
    `sort_order`   INT           DEFAULT 0       COMMENT '排序序号，越小越靠前',
    `status`       TINYINT       DEFAULT 1       COMMENT '1启用 0禁用',
    `created_time` DATETIME      DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`id`),
    KEY `idx_category` (`category`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='兴趣标签表';

-- -----------------------------------------------------
-- 3. 用户-标签关联表
-- 一个用户可以有多个兴趣标签，每个标签有自评段位
-- -----------------------------------------------------
DROP TABLE IF EXISTS `user_tag`;
CREATE TABLE `user_tag` (
    `id`           BIGINT   NOT NULL AUTO_INCREMENT COMMENT '主键',
    `user_id`      BIGINT   NOT NULL                COMMENT '用户ID',
    `tag_id`       BIGINT   NOT NULL                COMMENT '标签ID',
    `self_level`   INT      DEFAULT 1               COMMENT '自评段位 1青铜 2白银 3黄金 4钻石 5王者',
    `created_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_tag` (`user_id`, `tag_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户标签关联表';

-- -----------------------------------------------------
-- 4. 组局帖子表
-- 核心业务表，记录所有"找搭子"的帖子
-- status: RECRUITING(招募中) -> FULL(已满员) -> ONGOING(进行中) -> FINISHED(已结束)
--         还可能被 CANCELLED(已取消)
-- -----------------------------------------------------
DROP TABLE IF EXISTS `post`;
CREATE TABLE `post` (
    `id`             BIGINT        NOT NULL AUTO_INCREMENT COMMENT '主键',
    `publisher_id`   BIGINT        NOT NULL             COMMENT '发布人ID',
    `title`          VARCHAR(128)  NOT NULL             COMMENT '帖子标题',
    `category`       VARCHAR(64)   NOT NULL             COMMENT '所属分类，如 球类/电竞',
    `tag_ids`        VARCHAR(255)  DEFAULT NULL         COMMENT '相关标签id列表，逗号分隔',
    `start_time`     DATETIME      NOT NULL             COMMENT '活动开始时间',
    `end_time`       DATETIME      NOT NULL             COMMENT '活动结束时间',
    `location`       VARCHAR(128)  NOT NULL             COMMENT '活动地点',
    `max_people`     INT           NOT NULL DEFAULT 2   COMMENT '最大人数',
    `current_people` INT           NOT NULL DEFAULT 1   COMMENT '当前人数(含发布者)',
    `require_level`  INT           DEFAULT NULL         COMMENT '要求最低段位，空则不限',
    `require_gender` TINYINT       DEFAULT 0             COMMENT '要求性别 0不限 1男 2女',
    `description`    TEXT                               COMMENT '活动描述',
    `status`         VARCHAR(24)   NOT NULL DEFAULT 'RECRUITING' COMMENT '状态：RECRUITING/FULL/ONGOING/FINISHED/CANCELLED',
    `view_count`     INT           DEFAULT 0            COMMENT '浏览量',
    `like_count`     INT           DEFAULT 0            COMMENT '点赞数',
    `is_audit_pass`  TINYINT       DEFAULT 1             COMMENT '管理员审核 1通过 0待审',
    `created_time`   DATETIME      DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_time`   DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    KEY `idx_publisher` (`publisher_id`),
    KEY `idx_status_time` (`status`, `start_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='组局帖子表';

-- -----------------------------------------------------
-- 5. 报名表
-- 记录用户对帖子的报名信息
-- status: PENDING(待审核) -> APPROVED(已加入) / REJECTED(已拒绝)
--         APPROVED 还可能变为 CANCELLED(已退出) / ATTENDED(已参加) / NOSHOW(爽约)
-- -----------------------------------------------------
DROP TABLE IF EXISTS `post_apply`;
CREATE TABLE `post_apply` (
    `id`           BIGINT        NOT NULL AUTO_INCREMENT COMMENT '主键',
    `post_id`      BIGINT        NOT NULL                COMMENT '帖子ID',
    `applicant_id` BIGINT        NOT NULL                COMMENT '申请人ID',
    `status`       VARCHAR(24)   NOT NULL DEFAULT 'PENDING' COMMENT '状态：PENDING/APPROVED/REJECTED/CANCELLED/ATTENDED/NOSHOW',
    `apply_time`   DATETIME      DEFAULT CURRENT_TIMESTAMP COMMENT '申请时间',
    `handle_time`  DATETIME      DEFAULT NULL            COMMENT '处理时间',
    `remark`       VARCHAR(255)  DEFAULT NULL            COMMENT '备注',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_post_applicant` (`post_id`, `applicant_id`),
    KEY `idx_applicant` (`applicant_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='报名表';

-- -----------------------------------------------------
-- 6. 评价表
-- 活动结束后，参与者之间互相评价
-- -----------------------------------------------------
DROP TABLE IF EXISTS `review`;
CREATE TABLE `review` (
    `id`             BIGINT        NOT NULL AUTO_INCREMENT COMMENT '主键',
    `post_id`        BIGINT        NOT NULL           COMMENT '帖子ID',
    `reviewer_id`    BIGINT        NOT NULL           COMMENT '评价人ID',
    `target_user_id` BIGINT        NOT NULL           COMMENT '被评价人ID',
    `rating`         TINYINT       NOT NULL           COMMENT '评分 1-5星',
    `tag`            VARCHAR(32)   DEFAULT NULL       COMMENT '评价标签：靠谱/爽约/迟到',
    `content`        VARCHAR(500)  DEFAULT NULL       COMMENT '评价内容',
    `created_time`   DATETIME      DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_post_reviewer_target` (`post_id`, `reviewer_id`, `target_user_id`),
    KEY `idx_target` (`target_user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='评价表';

-- -----------------------------------------------------
-- 7. 评论表
-- 帖子下的评论，类似朋友圈评论
-- -----------------------------------------------------
DROP TABLE IF EXISTS `post_comment`;
CREATE TABLE `post_comment` (
    `id`           BIGINT        NOT NULL AUTO_INCREMENT COMMENT '主键',
    `post_id`      BIGINT        NOT NULL                COMMENT '帖子ID',
    `user_id`      BIGINT        NOT NULL                COMMENT '评论用户ID',
    `content`      VARCHAR(500)  NOT NULL                COMMENT '评论内容',
    `created_time` DATETIME      DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`id`),
    KEY `idx_post` (`post_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='评论表';
```

### 解释

**7 张表的关系图：**

```
sys_user ──1:N──> user_tag ──N:1──> interest_tag
   │
   ├──1:N──> post (作为发布者)
   │           │
   │           ├──1:N──> post_apply (作为申请人)
   │           ├──1:N──> post_comment
   │           └──1:N──> review
   │
   └──1:N──> post_apply (作为申请人)
```

**关键设计说明：**

| 表名 | 用途 | 关键字段 |
|------|------|----------|
| `sys_user` | 用户信息，含信誉分和管理员标识 | `credit_score`、`is_admin` |
| `interest_tag` | 兴趣标签，管理员维护 | `category` 分类、`sort_order` 排序 |
| `user_tag` | 用户和标签的多对多关联 | `self_level` 自评段位 |
| `post` | 核心业务表——找搭子帖子 | `status` 状态机、`require_level` 段位要求 |
| `post_apply` | 报名记录，含状态流转 | `status` 从 PENDING 到 APPROVED/NOSHOW |
| `review` | 活动后互评 | `rating` 1-5 星、`tag` 标签 |
| `post_comment` | 帖子评论 | 简单的帖子-用户-内容关联 |

**为什么用户表叫 `sys_user` 而不是 `user`？** `user` 是 MySQL 的保留字，直接用容易出问题，加 `sys_` 前缀更安全。

**为什么 post 表的 `status` 用 VARCHAR 而不是 TINYINT？** 用字符串状态（RECRUITING、FULL 等）可读性更好，调试时看数据库一眼就知道状态，不需要查字典表。这是状态机模式的常见做法。

**为什么 `post_apply` 有唯一索引 `uk_post_applicant`？** 防止同一个用户重复报名同一个帖子。

## 第七步：创建 Spring Security 配置（临时放行）

> ⚠️ Spring Security 默认会拦截所有请求，导致项目启动后所有接口都返回 401。我们需要先放行所有请求，后续 Day03 会用自定义 JWT 拦截器来做认证。

### 创建文件

`src/main/java/com/buddy/config/SecurityConfig.java`

### 写入代码

```java
package com.buddy.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.web.SecurityFilterChain;

/**
 * Spring Security 配置
 * 关闭 CSRF 和 Session，放行所有请求（JWT 认证由自定义拦截器处理）
 */
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
                // 关闭 CSRF（前后端分离项目不需要）
                .csrf().disable()
                // 关闭 Session，使用无状态方式
                .sessionManagement().sessionCreationPolicy(SessionCreationPolicy.STATELESS)
                .and()
                // 放行所有请求，JWT 认证由自定义拦截器处理
                .authorizeRequests()
                .anyRequest().permitAll()
                .and()
                // 禁用 frameOptions，允许 iframe 嵌入
                .headers().frameOptions().disable();

        return http.build();
    }
}
```

### 解释

- **为什么要关闭 CSRF？** CSRF（跨站请求伪造）防护是给传统表单提交用的，前后端分离项目用 JWT Token 认证，不需要 CSRF 防护
- **为什么要关闭 Session？** 我们用 JWT 做无状态认证，不需要服务器端 Session，设为 `STATELESS` 可以节省内存
- **为什么要放行所有请求？** 因为我们用自定义的 `JwtInterceptor` 来做认证和鉴权，不需要 Spring Security 的过滤器链来管
