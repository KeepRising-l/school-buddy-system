### 创建文件

### 写入代码

```java
package com.buddy.common.constant;

/**
 * 报名状态常量
 */
public class ApplyStatus {

    /** 待审核 */
    public static final String PENDING = "PENDING";
    /** 已通过 */
    public static final String APPROVED = "APPROVED";
    /** 已拒绝 */
    public static final String REJECTED = "REJECTED";
    /** 已取消 */
    public static final String CANCELLED = "CANCELLED";
    /** 已出勤 */
    public static final String ATTENDED = "ATTENDED";
    /** 未到场（爽约） */
    public static final String NOSHOW = "NOSHOW";

    private ApplyStatus() {
    }
}
```

### 解释

- 报名有 6 种状态，代表报名的完整生命周期：
  - `PENDING`：刚报名，等待发布者审批。
  - `APPROVED`：发布者同意了，可以参加活动。
  - `REJECTED`：发布者拒绝了，不能参加。
  - `CANCELLED`：报名者自己取消了报名。
  - `ATTENDED`：活动结束后，发布者标记该报名者已到场。
  - `NOSHOW`：活动结束后，发布者标记该报名者未到场（爽约），会扣信誉分。
- 状态流转：
  ```
  PENDING → APPROVED（发布者同意）
  PENDING → REJECTED（发布者拒绝）
  PENDING/APPROVED → CANCELLED（报名者取消）
  APPROVED → ATTENDED（发布者标记出勤）
  APPROVED → NOSHOW（发布者标记爽约，扣10分）
  ```

```java
package com.buddy.common.constant;

/**
 * 信誉分常量
 */
public class CreditConstant {

    /** 初始信誉分 */
    public static final int INITIAL_SCORE = 100;
    /** 最低信誉分 */
    public static final int MIN_SCORE = 0;
    /** 最高信誉分 */
    public static final int MAX_SCORE = 100;
    /** 惩罚阈值，低于此分数将受限 */
    public static final int PUNISH_THRESHOLD = 60;
    /** 惩罚系数 */
    public static final double PUNISH_FACTOR = 0.3;

    /** 靠谱评价 +2 */
    public static final int RELIABLE_BONUS = 2;
    /** 4星评价 +1 */
    public static final int FOUR_STAR_BONUS = 1;
    /** 迟到 -3 */
    public static final int LATE_PENALTY = -3;
    /** 爽约 -10 */
    public static final int NOSHOW_PENALTY = -10;
    /** 爽约额外 -5 */
    public static final int NOSHOW_EXTRA_PENALTY = -5;
    /** 临场取消 -5 */
    public static final int CANCEL_LAST_MINUTE = -5;

    private CreditConstant() {
    }
}
```

### 解释

- `INITIAL_SCORE = 100`：新用户初始信誉分 100 分。
- `MIN_SCORE = 0`：信誉分最低为 0，不能为负数。
- `MAX_SCORE = 100`：信誉分最高为 100，不能超过。
- `PUNISH_THRESHOLD = 60`：低于 60 分的用户受限（不能发布帖子、不能报名）。
- `NOSHOW_PENALTY = -10`：爽约扣 10 分。这是最严重的惩罚，因为爽约直接影响其他人的活动体验。
- `CANCEL_LAST_MINUTE = -5`：活动开始前 1 小时内取消报名扣 5 分。临场取消会让发布者措手不及，所以也要惩罚。
- `RELIABLE_BONUS = 2`：被评价为"靠谱"或 5 星好评，信誉分 +2。
- `LATE_PENALTY = -3`：被评价为"迟到"，信誉分 -3。
- 所有常量用 `public static final` 修饰，表示全局不可变。使用时通过 `CreditConstant.NOSHOW_PENALTY` 引用，而不是硬编码 `-10`，方便统一修改。

### 创建文件

`backend/src/main/java/com/buddy/service/impl/CreditServiceImpl.java`

### 写入代码

```java
package com.buddy.service.impl;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.buddy.common.constant.CreditConstant;
import com.buddy.entity.Review;
import com.buddy.entity.User;
import com.buddy.mapper.ReviewMapper;
import com.buddy.mapper.UserMapper;
import com.buddy.service.CreditService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

/**
 * 信誉分服务实现类
 */
@Service
public class CreditServiceImpl implements CreditService {

    @Autowired
    private ReviewMapper reviewMapper;

    @Autowired
    private UserMapper userMapper;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void recalculateUserCredit(Long userId) {
        User user = userMapper.selectById(userId);
        if (user == null) {
            return;
        }

        // 查询用户所有收到的评价
        List<Review> reviews = reviewMapper.selectList(
                new LambdaQueryWrapper<Review>().eq(Review::getTargetUserId, userId)
        );

        // 计算信誉分 = 100 + Σ评价影响
        int creditScore = CreditConstant.INITIAL_SCORE;
        for (Review review : reviews) {
            creditScore += calculateReviewImpact(review);
        }

        // 限制0-100
        creditScore = Math.max(CreditConstant.MIN_SCORE, Math.min(CreditConstant.MAX_SCORE, creditScore));

        // 更新数据库
        user.setCreditScore(creditScore);
        userMapper.updateById(user);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void recalculateAllCredit() {
        // 查询所有正常状态的用户
        List<User> users = userMapper.selectList(
                new LambdaQueryWrapper<User>().eq(User::getStatus, 1)
        );

        // 逐个重新计算
        for (User user : users) {
            recalculateUserCredit(user.getId());
        }
    }

    @Override
    public int getCreditLevel(Integer creditScore) {
        if (creditScore == null) {
            return 1;
        }
        if (creditScore >= 90) {
            return 5;
        } else if (creditScore >= 75) {
            return 4;
        } else if (creditScore >= 60) {
            return 3;
        } else if (creditScore >= 40) {
            return 2;
        } else {
            return 1;
        }
    }

    @Override
    public String getCreditLabel(Integer creditScore) {
        int level = getCreditLevel(creditScore);
        switch (level) {
            case 5:
                return "靠谱队友";
            case 4:
                return "优质队友";
            case 3:
                return "普通队友";
            case 2:
                return "风险队友";
            case 1:
                return "失信队友";
            default:
                return "未知";
        }
    }

    @Override
    public boolean isLowCredit(Integer creditScore) {
        return creditScore != null && creditScore < CreditConstant.PUNISH_THRESHOLD;
    }

    /**
     * 计算单条评价对信誉分的影响
     */
    private int calculateReviewImpact(Review review) {
        int impact = 0;

        // 根据评分计算影响
        if (review.getRating() != null) {
            if (review.getRating() == 5) {
                impact += CreditConstant.RELIABLE_BONUS;
            } else if (review.getRating() == 4) {
                impact += CreditConstant.FOUR_STAR_BONUS;
            }
        }

        // 根据标签计算影响
        if (review.getTag() != null) {
            switch (review.getTag()) {
                case "靠谱":
                    impact += CreditConstant.RELIABLE_BONUS;
                    break;
                case "迟到":
                    impact += CreditConstant.LATE_PENALTY;
                    break;
                case "爽约":
                    impact += CreditConstant.NOSHOW_PENALTY;
                    impact += CreditConstant.NOSHOW_EXTRA_PENALTY;
                    break;
                default:
                    break;
            }
        }

        return impact;
    }
}
```

### 解释

#### getCreditLevel() 方法

信誉分转星级的规则：

| 信誉分范围 | 星级 | 标签 |
|-----------|------|------|
| 90-100 | 5 星 | 靠谱队友 |
| 75-89 | 4 星 | 优质队友 |
| 60-74 | 3 星 | 普通队友 |
| 40-59 | 2 星 | 风险队友 |
| 0-39 | 1 星 | 失信队友 |

- 90 分以上是最高等级"靠谱队友"，表示这个用户非常可靠。
- 60 分是及格线，低于 60 分的用户会受到限制（不能发布帖子、不能报名）。
- 40 分以下是最差等级"失信队友"，前端会显示红色警告标识。

#### isLowCredit() 方法

- 判断信誉分是否低于惩罚阈值（60 分）。
- 在报名和发帖时调用，信誉分过低的用户会被拒绝操作。

#### recalculateUserCredit() 方法

- 重新计算用户信誉分：从 100 分开始，加上所有评价的影响。
- 评价影响包括：5 星好评 +2 分，4 星好评 +1 分，"靠谱"标签 +2 分，"迟到"标签 -3 分，"爽约"标签 -15 分（-10 + -5）。
- 最终分数限制在 0-100 之间。

#### calculateReviewImpact() 方法

- 计算单条评价对信誉分的影响值。
- 评分和标签的影响可以叠加。比如一条评价同时打了 5 星和"靠谱"标签，总影响是 +4 分。

## 第六步：创建 ApplyServiceImpl

### 创建文件

`backend/src/main/java/com/buddy/service/impl/ApplyServiceImpl.java`

### 写入代码

```java
package com.buddy.service.impl;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.core.metadata.IPage;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.buddy.common.constant.ApplyStatus;
import com.buddy.common.constant.CreditConstant;
import com.buddy.common.constant.PostStatus;
import com.buddy.common.exception.BusinessException;
import com.buddy.common.result.ResultCode;
import com.buddy.common.statemachine.PostStateMachine;
import com.buddy.dto.response.ApplyVO;
import com.buddy.entity.Post;
import com.buddy.entity.PostApply;
import com.buddy.entity.User;
import com.buddy.entity.UserTag;
import com.buddy.mapper.PostApplyMapper;
import com.buddy.mapper.PostMapper;
import com.buddy.mapper.UserMapper;
import com.buddy.mapper.UserTagMapper;
import com.buddy.service.ApplyService;
import com.buddy.service.CreditService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDateTime;
import java.util.List;
import java.util.stream.Collectors;

/**
 * 报名服务实现类
 */
@Service
public class ApplyServiceImpl implements ApplyService {

    @Autowired
    private PostApplyMapper postApplyMapper;

    @Autowired
    private PostMapper postMapper;

    @Autowired
    private UserMapper userMapper;

    @Autowired
    private UserTagMapper userTagMapper;

    @Autowired
    private CreditService creditService;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void apply(Long userId, Long postId) {
        // 校验帖子存在且状态为RECRUITING
        Post post = postMapper.selectById(postId);
        if (post == null) {
            throw new BusinessException(ResultCode.NOT_FOUND, "帖子不存在");
        }
        if (!PostStatus.RECRUITING.equals(post.getStatus())) {
            throw new BusinessException(ResultCode.POST_NOT_RECRUITING);
        }

        // 校验不能报名自己发布的帖子
        if (post.getPublisherId().equals(userId)) {
            throw new BusinessException("不能报名自己发布的活动");
        }

        // 校验未重复报名
        Long applyCount = postApplyMapper.selectCount(
                new LambdaQueryWrapper<PostApply>()
                        .eq(PostApply::getPostId, postId)
                        .eq(PostApply::getApplicantId, userId)
                        .ne(PostApply::getStatus, ApplyStatus.CANCELLED)
        );
        if (applyCount > 0) {
            throw new BusinessException(ResultCode.APPLY_DUPLICATE);
        }

        // 校验信誉分
        User applicant = userMapper.selectById(userId);
        if (applicant == null) {
            throw new BusinessException(ResultCode.USER_NOT_FOUND);
        }
        if (creditService.isLowCredit(applicant.getCreditScore())) {
            throw new BusinessException(ResultCode.CREDIT_TOO_LOW);
        }

        // 校验段位要求
        if (post.getRequireLevel() != null) {
            UserTag userTag = userTagMapper.selectOne(
                    new LambdaQueryWrapper<UserTag>()
                            .eq(UserTag::getUserId, userId)
                            .eq(UserTag::getTagId, parseFirstTagId(post.getTagIds()))
                            .last("LIMIT 1")
            );
            if (userTag == null || userTag.getSelfLevel() < post.getRequireLevel()) {
                throw new BusinessException(ResultCode.APPLY_NOT_QUALIFIED, "段位不满足要求");
            }
        }

        // 校验性别要求
        if (post.getRequireGender() != null && post.getRequireGender() != 0) {
            if (!post.getRequireGender().equals(applicant.getGender())) {
                throw new BusinessException(ResultCode.APPLY_NOT_QUALIFIED, "性别不满足要求");
            }
        }

        // 插入报名记录
        PostApply apply = new PostApply();
        apply.setPostId(postId);
        apply.setApplicantId(userId);
        apply.setStatus(ApplyStatus.PENDING);
        apply.setApplyTime(LocalDateTime.now());

        postApplyMapper.insert(apply);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void cancelApply(Long userId, Long applyId) {
        PostApply apply = postApplyMapper.selectById(applyId);
        if (apply == null) {
            throw new BusinessException(ResultCode.NOT_FOUND, "报名记录不存在");
        }

        // 校验是报名者本人
        if (!apply.getApplicantId().equals(userId)) {
            throw new BusinessException(ResultCode.FORBIDDEN, "只能取消自己的报名");
        }

        // 校验状态可取消（PENDING或APPROVED才能取消）
        if (!ApplyStatus.PENDING.equals(apply.getStatus()) && !ApplyStatus.APPROVED.equals(apply.getStatus())) {
            throw new BusinessException("当前报名状态不可取消");
        }

        // 记录取消前的状态（用于后续判断是否减人数）
        boolean wasApproved = ApplyStatus.APPROVED.equals(apply.getStatus());

        // 更新报名状态
        apply.setStatus(ApplyStatus.CANCELLED);
        apply.setHandleTime(LocalDateTime.now());
        postApplyMapper.updateById(apply);

        // 获取帖子信息
        Post post = postMapper.selectById(apply.getPostId());
        if (post == null) {
            return;
        }

        // 如果帖子状态为FULL，回退为RECRUITING
        if (PostStatus.FULL.equals(post.getStatus())) {
            if (PostStateMachine.canTransit(PostStatus.FULL, PostStatus.RECRUITING)) {
                post.setStatus(PostStatus.RECRUITING);
                postMapper.updateById(post);
            }
        }

        // APPROVED状态的报名取消才减人数
        if (wasApproved) {
            post.setCurrentPeople(Math.max(1, post.getCurrentPeople() - 1));
            postMapper.updateById(post);
        }

        // 活动开始前1小时内取消报名，扣除信誉分5分
        if (post.getStartTime() != null) {
            LocalDateTime now = LocalDateTime.now();
            LocalDateTime startTime = post.getStartTime();
            // 活动开始前1小时内取消
            if (now.isAfter(startTime.minusHours(1)) && now.isBefore(startTime.plusHours(24))) {
                User applicant = userMapper.selectById(userId);
                if (applicant != null) {
                    int newScore = Math.max(CreditConstant.MIN_SCORE,
                            applicant.getCreditScore() + CreditConstant.CANCEL_LAST_MINUTE);
                    applicant.setCreditScore(newScore);
                    userMapper.updateById(applicant);
                }
            }
        }
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void approve(Long publisherId, Long applyId) {
        PostApply apply = postApplyMapper.selectById(applyId);
        if (apply == null) {
            throw new BusinessException(ResultCode.NOT_FOUND, "报名记录不存在");
        }

        // 校验是发布者
        Post post = postMapper.selectById(apply.getPostId());
        if (post == null || !post.getPublisherId().equals(publisherId)) {
            throw new BusinessException(ResultCode.FORBIDDEN, "只有发布者才能审批报名");
        }

        // 校验报名状态为PENDING
        if (!ApplyStatus.PENDING.equals(apply.getStatus())) {
            throw new BusinessException("只能审批待审核的报名");
        }

        // 更新报名状态为APPROVED
        apply.setStatus(ApplyStatus.APPROVED);
        apply.setHandleTime(LocalDateTime.now());
        postApplyMapper.updateById(apply);

        // current_people+1
        post.setCurrentPeople(post.getCurrentPeople() + 1);

        // 检查是否满员
        if (post.getCurrentPeople() >= post.getMaxPeople()) {
            PostStateMachine.checkTransition(post.getStatus(), PostStatus.FULL);
            post.setStatus(PostStatus.FULL);
        }

        postMapper.updateById(post);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void reject(Long publisherId, Long applyId) {
        PostApply apply = postApplyMapper.selectById(applyId);
        if (apply == null) {
            throw new BusinessException(ResultCode.NOT_FOUND, "报名记录不存在");
        }

        // 校验是发布者
        Post post = postMapper.selectById(apply.getPostId());
        if (post == null || !post.getPublisherId().equals(publisherId)) {
            throw new BusinessException(ResultCode.FORBIDDEN, "只有发布者才能审批报名");
        }

        // 校验报名状态为PENDING
        if (!ApplyStatus.PENDING.equals(apply.getStatus())) {
            throw new BusinessException("只能拒绝待审核的报名");
        }

        // 更新报名状态为REJECTED
        apply.setStatus(ApplyStatus.REJECTED);
        apply.setHandleTime(LocalDateTime.now());
        postApplyMapper.updateById(apply);
    }

    @Override
    public List<ApplyVO> getApplyList(Long postId) {
        List<PostApply> applies = postApplyMapper.selectList(
                new LambdaQueryWrapper<PostApply>()
                        .eq(PostApply::getPostId, postId)
                        .orderByDesc(PostApply::getApplyTime)
        );
        return applies.stream().map(apply -> {
            ApplyVO vo = new ApplyVO();
            vo.setId(apply.getId());
            vo.setPostId(apply.getPostId());
            vo.setApplicantId(apply.getApplicantId());
            vo.setStatus(apply.getStatus());
            vo.setApplyTime(apply.getApplyTime());
            vo.setHandleTime(apply.getHandleTime());
            vo.setRemark(apply.getRemark());

            // 查询申请人信息
            User applicant = userMapper.selectById(apply.getApplicantId());
            if (applicant != null) {
                vo.setApplicantNickname(applicant.getNickname());
                vo.setApplicantAvatar(applicant.getAvatar());
                vo.setApplicantCreditLevel(creditService.getCreditLevel(applicant.getCreditScore()));
            }
            return vo;
        }).collect(Collectors.toList());
    }

    @Override
    public IPage<PostApply> getReceivedApplies(Long userId, int page, int size) {
        // 查询当前用户发布的帖子ID列表
        List<Post> myPosts = postMapper.selectList(
                new LambdaQueryWrapper<Post>().eq(Post::getPublisherId, userId)
        );
        if (myPosts.isEmpty()) {
            return new Page<>(page, size);
        }

        List<Long> postIds = myPosts.stream().map(Post::getId).collect(Collectors.toList());

        // 查询这些帖子的报名记录
        return postApplyMapper.selectPage(
                new Page<>(page, size),
                new LambdaQueryWrapper<PostApply>()
                        .in(PostApply::getPostId, postIds)
                        .orderByDesc(PostApply::getApplyTime)
        );
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void markAttendance(Long publisherId, Long applyId, boolean attended) {
        PostApply apply = postApplyMapper.selectById(applyId);
        if (apply == null) {
            throw new BusinessException(ResultCode.NOT_FOUND, "报名记录不存在");
        }

        // 校验是帖子发布者
        Post post = postMapper.selectById(apply.getPostId());
        if (post == null || !post.getPublisherId().equals(publisherId)) {
            throw new BusinessException(ResultCode.FORBIDDEN, "只有发布者才能标记出勤");
        }

        // 校验帖子状态为ONGOING或FINISHED
        if (!PostStatus.ONGOING.equals(post.getStatus()) && !PostStatus.FINISHED.equals(post.getStatus())) {
            throw new BusinessException("活动进行中或已结束时才能标记出勤");
        }

        // 校验报名状态为APPROVED
        if (!ApplyStatus.APPROVED.equals(apply.getStatus())) {
            throw new BusinessException("只能标记已通过的报名出勤状态");
        }

        // 更新出勤状态
        apply.setStatus(attended ? ApplyStatus.ATTENDED : ApplyStatus.NOSHOW);
        apply.setHandleTime(LocalDateTime.now());
        postApplyMapper.updateById(apply);

        // 未到场扣信誉分10分
        if (!attended) {
            User applicant = userMapper.selectById(apply.getApplicantId());
            if (applicant != null) {
                int newScore = Math.max(CreditConstant.MIN_SCORE,
                        applicant.getCreditScore() + CreditConstant.NOSHOW_PENALTY);
                applicant.setCreditScore(newScore);
                userMapper.updateById(applicant);
            }
        }
    }

    /**
     * 解析帖子tagIds中的第一个标签ID
     */
    private Long parseFirstTagId(String tagIds) {
        if (tagIds == null || tagIds.isEmpty()) {
            return null;
        }
        String[] ids = tagIds.split(",");
        return Long.parseLong(ids[0].trim());
    }
}
```

### 解释

#### apply() 方法

报名参加活动的完整校验流程：

1. **校验帖子状态**：只有 RECRUITING（招募中）状态的帖子才能报名。FULL 状态的帖子不能报名（人已满）。
2. **校验不能报名自己的帖子**：发布者不需要报名自己的活动，自己就是参与者。
3. **校验未重复报名**：查询该用户对该帖子的报名记录（排除已取消的），如果存在则拒绝。`ne(PostApply::getStatus, ApplyStatus.CANCELLED)` 排除已取消的记录，因为取消后应该可以重新报名。
4. **校验信誉分**：信誉分低于 60 分的用户不能报名。
5. **校验段位要求**：如果帖子设置了 `requireLevel`，查询报名者在对应标签上的自评段位，不满足则拒绝。比如帖子要求"篮球黄金以上"，报名者的篮球段位是白银，就会被拒绝。
6. **校验性别要求**：如果帖子设置了 `requireGender`（1=仅男、2=仅女），报名者的性别不匹配则拒绝。
7. 通过所有校验后，插入报名记录，状态为 PENDING（待审核）。

#### cancelApply() 方法

取消报名的逻辑比较复杂，需要处理多种情况：

1. **校验是本人**：只能取消自己的报名。
2. **校验状态可取消**：只有 PENDING 和 APPROVED 状态的报名才能取消。已经 REJECTED、ATTENDED、NOSHOW 的不能取消。
3. **记录取消前状态**：在更新状态之前，先记录报名当前是否是 APPROVED 状态。因为更新后状态就变了，后续判断需要用到。
4. **更新报名状态为 CANCELLED**。
5. **帖子状态回退**：如果帖子是 FULL（满员）状态，有人取消后就不满员了，需要回退为 RECRUITING。用状态机的 `canTransit()` 判断是否可以回退。
6. **减人数**：只有 APPROVED 状态的报名取消才减人数（因为 PENDING 状态的报名还没被计入 currentPeople）。
7. **临场取消扣分**：如果活动开始前 1 小时内取消报名，扣信誉分 5 分。这是为了防止报名者临阵脱逃，影响活动正常进行。
   - `now.isAfter(startTime.minusHours(1))`：当前时间在活动开始前 1 小时之后。
   - `now.isBefore(startTime.plusHours(24))`：当前时间在活动开始后 24 小时之内（防止活动结束后还扣分）。

#### approve() 方法

发布者同意报名：

1. **校验是发布者**：只有帖子发布者才能审批报名。
2. **校验报名状态为 PENDING**：只能审批待审核的报名，已通过或已拒绝的不能再审批。
3. **更新报名状态为 APPROVED**。
4. **currentPeople + 1**：通过一个报名，当前人数加 1。
5. **检查是否满员**：如果 `currentPeople >= maxPeople`，帖子状态改为 FULL。用状态机校验状态流转是否合法。

#### reject() 方法

发布者拒绝报名：

1. **校验是发布者**。
2. **校验报名状态为 PENDING**。
3. **更新报名状态为 REJECTED**。
4. 拒绝报名不需要减人数（因为 PENDING 状态的报名还没被计入 currentPeople）。

#### getApplyList() 方法

获取某个帖子的所有报名记录：

1. 查询 `post_apply` 表中 `post_id = postId` 的所有记录，按申请时间倒序。
2. 将 `PostApply` 实体转换为 `ApplyVO`，同时查询报名者的昵称、头像、信誉星级。

#### getReceivedApplies() 方法

获取当前用户收到的所有报名申请：

1. 先查询当前用户发布的所有帖子 ID。
2. 再查询这些帖子的报名记录，分页返回。
3. 如果用户没有发布过帖子，返回空分页。

#### markAttendance() 方法

标记出勤状态，这是信誉分扣减的核心入口：

1. **校验是帖子发布者**：只有发布者才能标记出勤。
2. **校验帖子状态**：只有 ONGOING（进行中）或 FINISHED（已结束）的帖子才能标记出勤。活动还没开始不能标记。
3. **校验报名状态为 APPROVED**：只有已通过的报名才能标记出勤。PENDING 状态的还没通过，不需要标记。
4. **更新出勤状态**：`attended=true` 设为 ATTENDED，`attended=false` 设为 NOSHOW。
5. **NOSHOW 扣 10 分**：爽约是最严重的违规行为，直接扣 10 分。用 `Math.max(MIN_SCORE, ...)` 确保信誉分不会低于 0。

## 第七步：创建 ApplyController

### 创建文件

`backend/src/main/java/com/buddy/controller/user/ApplyController.java`

### 写入代码

```java
package com.buddy.controller.user;

import com.baomidou.mybatisplus.core.metadata.IPage;
import com.buddy.common.context.UserContext;
import com.buddy.common.result.R;
import com.buddy.dto.response.ApplyVO;
import com.buddy.entity.PostApply;
import com.buddy.service.ApplyService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

import java.util.List;
import java.util.Map;

/**
 * 报名控制器
 */
@RestController
@RequestMapping("/api/apply")
public class ApplyController {

    @Autowired
    private ApplyService applyService;

    /**
     * 报名
     * body: {postId: 1}
     */
    @PostMapping("/join")
    public R<Void> apply(@RequestBody Map<String, Object> body) {
        Long userId = UserContext.getUserId();
        Long postId = Long.valueOf(body.get("postId").toString());
        applyService.apply(userId, postId);
        return R.ok();
    }

    /**
     * 取消报名
     */
    @PostMapping("/cancel/{id}")
    public R<Void> cancelApply(@PathVariable Long id) {
        Long userId = UserContext.getUserId();
        applyService.cancelApply(userId, id);
        return R.ok();
    }

    /**
     * 报名列表（发布者查看）
     */
    @GetMapping("/list/{postId}")
    public R<List<ApplyVO>> getApplyList(@PathVariable Long postId) {
        return R.ok(applyService.getApplyList(postId));
    }

    /**
     * 同意报名
     */
    @PostMapping("/approve/{id}")
    public R<Void> approve(@PathVariable Long id) {
        Long userId = UserContext.getUserId();
        applyService.approve(userId, id);
        return R.ok();
    }

    /**
     * 拒绝报名
     */
    @PostMapping("/reject/{id}")
    public R<Void> reject(@PathVariable Long id) {
        Long userId = UserContext.getUserId();
        applyService.reject(userId, id);
        return R.ok();
    }

    /**
     * 收到的报名申请
     */
    @GetMapping("/received")
    public R<IPage<PostApply>> getReceivedApplies(
            @RequestParam(defaultValue = "1") int page,
            @RequestParam(defaultValue = "10") int size) {
        Long userId = UserContext.getUserId();
        return R.ok(applyService.getReceivedApplies(userId, page, size));
    }

    /**
     * 标记出勤状态
     * body: {attended: true/false}
     */
    @PostMapping("/attendance/{id}")
    public R<Void> markAttendance(@PathVariable Long id, @RequestBody Map<String, Object> body) {
        Long userId = UserContext.getUserId();
        boolean attended = Boolean.parseBoolean(body.get("attended").toString());
        applyService.markAttendance(userId, id, attended);
        return R.ok();
    }
}
```

### 解释

- `apply`（报名）：接收 `postId`，调用 Service 进行报名。
- `cancelApply`（取消报名）：URL 中的 `id` 是报名记录 ID（不是帖子 ID）。
- `getApplyList`（报名列表）：发布者查看某个帖子的所有报名记录。
- `approve` / `reject`（审批报名）：URL 中的 `id` 是报名记录 ID。
- `getReceivedApplies`（收到的报名）：当前用户发布的所有帖子的报名记录，分页返回。
- `markAttendance`（标记出勤）：`attended=true` 表示已到场，`attended=false` 表示爽约。前端传 `{"attended": true}` 或 `{"attended": false}`。
