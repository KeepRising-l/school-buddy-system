## 第一步：创建 PostCreateRequest DTO

### 创建文件

`backend/src/main/java/com/buddy/dto/request/PostCreateRequest.java`

### 写入代码

```java
package com.buddy.dto.request;

import lombok.Data;

import javax.validation.constraints.*;
import java.time.LocalDateTime;

/**
 * 发帖请求
 */
@Data
public class PostCreateRequest {

    @NotBlank
    @Size(min = 5, max = 30)
    private String title;

    @NotBlank
    private String category;

    /** 逗号分隔的标签ID */
    private String tagIds;

    @NotNull
    private LocalDateTime startTime;

    @NotNull
    private LocalDateTime endTime;

    @NotBlank
    private String location;

    @NotNull
    @Min(2)
    @Max(20)
    private Integer maxPeople;

    /** 要求最低段位，null不限 */
    private Integer requireLevel;

    /** 要求性别：0不限 1男 2女 */
    private Integer requireGender;

    @Size(max = 500)
    private String description;
}
```

### 解释

- `@NotBlank`：字符串不能为空，用于 title、category、location 等必填字段。
- `@Size(min = 5, max = 30)`：标题长度限制 5-30 个字符，太短或太长都不行。
- `@NotNull`：不能为 null，用于时间、人数等非字符串类型的必填字段。
- `@Min(2)` / `@Max(20)`：人数限制 2-20 人。至少 2 人（自己 + 1 个搭子），最多 20 人。
- `tagIds`：用逗号分隔的标签 ID 字符串，如 `"1,3,5"`。为什么不传 List？因为数据库中这个字段是 VARCHAR，直接存字符串更简单。
- `requireLevel` 和 `requireGender`：可选的报名限制条件。null 表示不限。
- `description`：活动描述，最长 500 字符。

- `requireLevel`、`requireGender`：报名限制条件，只在详情页展示，列表页不需要。
- `isAuditPass`：审核状态，0 待审核、1 已通过。列表页不展示，详情页展示给发布者看。
- `publisherSignature`、`publisherCollege`：发布者的个性签名和学院，帮助报名者了解发布者。
- `publisherTags`：发布者的兴趣标签列表（含段位），展示发布者擅长什么。
- `applyUsers`：已报名（APPROVED 和 PENDING 状态）的用户列表，发布者可以查看。
- `hasApplied`：当前登录用户是否已报名该帖子。前端根据这个值显示"报名"或"已报名"按钮。
- `applyStatus`：当前用户的报名状态（PENDING/APPROVED/REJECTED 等）。
- `myApplyId`：当前用户的报名记录 ID，用于取消报名时传给后端。

#### 内部类 ApplyUserVO

- 报名用户的摘要信息：ID、昵称、头像、信誉星级。
- `static` 修饰：静态内部类，不依赖外部类实例，可以独立创建。

#### 内部类 PublisherTagVO

- 发布者的兴趣标签：标签 ID、名称、分类、自评段位。
- 前端可以展示为"篮球 ⭐⭐⭐"这样的标签徽章。

### 创建文件

### 写入代码

```java
package com.buddy.common.constant;

/**
 * 帖子状态常量
 */
public class PostStatus {

    /** 招募中 */
    public static final String RECRUITING = "RECRUITING";
    /** 已满员 */
    public static final String FULL = "FULL";
    /** 进行中 */
    public static final String ONGOING = "ONGOING";
    /** 已结束 */
    public static final String FINISHED = "FINISHED";
    /** 已取消 */
    public static final String CANCELLED = "CANCELLED";

    private PostStatus() {
    }
}
```

### 解释

- 用常量类代替硬编码字符串，避免拼写错误。比如写 `"RECRUITTING"`（多了一个 T）编译器不会报错，但用 `PostStatus.RECRUITING` 写错就会编译失败。
- 私有构造方法：防止被实例化。这个类只提供常量，不需要创建对象。
- 状态含义：
  - `RECRUITING`：帖子刚发布，正在招募搭子。
  - `FULL`：报名人数已满，不再接受新报名。
  - `ONGOING`：活动正在进行中。
  - `FINISHED`：活动已结束。
  - `CANCELLED`：帖子被发布者或管理员取消。

## 第五步：创建 PostStateMachine 状态机

### 创建文件

`backend/src/main/java/com/buddy/common/statemachine/PostStateMachine.java`

### 写入代码

```java
package com.buddy.common.statemachine;

import com.buddy.common.constant.PostStatus;
import com.buddy.common.exception.BusinessException;
import com.buddy.common.result.ResultCode;

import java.util.Arrays;
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

/**
 * 帖子状态机校验器
 * 定义帖子状态的合法流转规则
 */
public class PostStateMachine {

    /** 合法的状态流转映射 */
    private static final Map<String, Set<String>> TRANSITIONS = new HashMap<>();

    static {
        // RECRUITING -> FULL, ONGOING, CANCELLED
        TRANSITIONS.put(PostStatus.RECRUITING, new HashSet<>(Arrays.asList(PostStatus.FULL, PostStatus.ONGOING, PostStatus.CANCELLED)));
        // FULL -> RECRUITING, ONGOING, CANCELLED
        TRANSITIONS.put(PostStatus.FULL, new HashSet<>(Arrays.asList(PostStatus.RECRUITING, PostStatus.ONGOING, PostStatus.CANCELLED)));
        // ONGOING -> FINISHED, CANCELLED（管理员可下架进行中的帖子）
        TRANSITIONS.put(PostStatus.ONGOING, new HashSet<>(Arrays.asList(PostStatus.FINISHED, PostStatus.CANCELLED)));
        // FINISHED 和 CANCELLED 是终态，不可流转
    }

    /**
     * 校验状态流转是否合法，不合法则抛出业务异常
     *
     * @param from 当前状态
     * @param to   目标状态
     */
    public static void checkTransition(String from, String to) {
        Set<String> allowedTargets = TRANSITIONS.get(from);
        if (allowedTargets == null || !allowedTargets.contains(to)) {
            throw new BusinessException(ResultCode.STATUS_TRANSIT_ERROR);
        }
    }

    /**
     * 判断是否可以流转到目标状态
     *
     * @param from 当前状态
     * @param to   目标状态
     * @return 是否可以流转
     */
    public static boolean canTransit(String from, String to) {
        Set<String> allowedTargets = TRANSITIONS.get(from);
        return allowedTargets != null && allowedTargets.contains(to);
    }
}
```

### 解释

- **状态机是什么？** 就是一个 Map，定义了"从哪个状态可以转到哪个状态"。本质上是一组 if-else 的封装。
- `TRANSITIONS` 的 key 是当前状态，value 是允许转换到的目标状态集合。
- 比如 `RECRUITING` 可以转到 `FULL`（人满了）、`ONGOING`（活动开始了）、`CANCELLED`（被取消了），但不能直接转到 `FINISHED`。
- `FULL` 可以回退到 `RECRUITING`（有人取消报名导致不满员了），也可以转到 `ONGOING` 或 `CANCELLED`。
- `FINISHED` 和 `CANCELLED` 是终态，不在 Map 中，意味着不能再转到任何状态。
- `checkTransition()`：校验不合法直接抛异常，用于业务逻辑中强制校验。
- `canTransit()`：返回 boolean，用于业务逻辑中判断是否可以流转（不抛异常）。

## 第七步：创建 PostServiceImpl

### 创建文件

### 写入代码

```java
package com.buddy.service.impl;

import cn.hutool.core.util.StrUtil;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.core.metadata.IPage;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.buddy.common.constant.CreditConstant;
import com.buddy.common.constant.PostStatus;
import com.buddy.common.exception.BusinessException;
import com.buddy.common.result.ResultCode;
import com.buddy.common.statemachine.PostStateMachine;
import com.buddy.dto.request.PostCreateRequest;
import com.buddy.dto.response.PostDetailVO;
import com.buddy.dto.response.PostVO;
import com.buddy.entity.Post;
import com.buddy.entity.PostApply;
import com.buddy.entity.User;
import com.buddy.entity.UserTag;
import com.buddy.entity.InterestTag;
import com.buddy.mapper.InterestTagMapper;
import com.buddy.mapper.PostApplyMapper;
import com.buddy.mapper.PostMapper;
import com.buddy.mapper.UserMapper;
import com.buddy.mapper.UserTagMapper;
import com.buddy.service.CreditService;
import com.buddy.service.PostService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.TimeUnit;
import java.util.stream.Collectors;

/**
 * 帖子服务实现类
 */
@Service
public class PostServiceImpl implements PostService {

    @Autowired
    private PostMapper postMapper;

    @Autowired
    private UserMapper userMapper;

    @Autowired
    private PostApplyMapper postApplyMapper;

    @Autowired
    private UserTagMapper userTagMapper;

    @Autowired
    private InterestTagMapper interestTagMapper;

    @Autowired
    private CreditService creditService;

    @Autowired
    private StringRedisTemplate redisTemplate;

    /** 浏览量去重缓存前缀 */
    private static final String VIEW_COUNT_KEY = "post:view:";

    /** 去重时间窗口（分钟） */
    private static final long VIEW_DEDUP_MINUTES = 10;

    /** 同时进行中帖子上限 */
    private static final int MAX_ACTIVE_POSTS = 5;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long createPost(Long userId, PostCreateRequest request) {
        // 校验信誉分
        User user = userMapper.selectById(userId);
        if (user == null) {
            throw new BusinessException(ResultCode.USER_NOT_FOUND);
        }
        if (creditService.isLowCredit(user.getCreditScore())) {
            throw new BusinessException(ResultCode.CREDIT_TOO_LOW);
        }

        // 校验同时进行中的帖子数量
        Long activeCount = postMapper.selectCount(
                new LambdaQueryWrapper<Post>()
                        .eq(Post::getPublisherId, userId)
                        .in(Post::getStatus, PostStatus.RECRUITING, PostStatus.FULL, PostStatus.ONGOING)
        );
        if (activeCount >= MAX_ACTIVE_POSTS) {
            throw new BusinessException("同时进行中的帖子不能超过" + MAX_ACTIVE_POSTS + "个");
        }

        // 构建帖子实体
        Post post = new Post();
        post.setPublisherId(userId);
        post.setTitle(request.getTitle());
        post.setCategory(request.getCategory());
        post.setTagIds(request.getTagIds());
        post.setStartTime(request.getStartTime());
        post.setEndTime(request.getEndTime());
        post.setLocation(request.getLocation());
        post.setMaxPeople(request.getMaxPeople());
        post.setCurrentPeople(1); // 发布者自己算1人
        post.setRequireLevel(request.getRequireLevel());
        post.setRequireGender(request.getRequireGender());
        post.setDescription(request.getDescription());
        post.setStatus(PostStatus.RECRUITING);
        post.setViewCount(0);
        post.setLikeCount(0);
        post.setIsAuditPass(0);

        postMapper.insert(post);
        return post.getId();
    }

    @Override
    public PostDetailVO getPostDetail(Long userId, Long postId) {
        Post post = postMapper.selectById(postId);
        if (post == null) {
            throw new BusinessException(ResultCode.NOT_FOUND, "帖子不存在");
        }

        // 查询发布者信息
        User publisher = userMapper.selectById(post.getPublisherId());

        // 查询已通过和待审核的报名用户列表
        List<PostApply> applies = postApplyMapper.selectList(
                new LambdaQueryWrapper<PostApply>()
                        .eq(PostApply::getPostId, postId)
                        .in(PostApply::getStatus, "APPROVED", "PENDING")
        );

        // 组装报名用户信息
        List<PostDetailVO.ApplyUserVO> applyUsers = new ArrayList<>();
        for (PostApply apply : applies) {
            User applyUser = userMapper.selectById(apply.getApplicantId());
            if (applyUser != null) {
                PostDetailVO.ApplyUserVO vo = new PostDetailVO.ApplyUserVO();
                vo.setUserId(applyUser.getId());
                vo.setNickname(applyUser.getNickname());
                vo.setAvatar(applyUser.getAvatar());
                vo.setCreditLevel(creditService.getCreditLevel(applyUser.getCreditScore()));
                applyUsers.add(vo);
            }
        }

        // 判断当前用户是否已报名
        boolean hasApplied = false;
        String applyStatus = null;
        Long myApplyId = null;
        if (userId != null) {
            PostApply myApply = postApplyMapper.selectOne(
                    new LambdaQueryWrapper<PostApply>()
                            .eq(PostApply::getPostId, postId)
                            .eq(PostApply::getApplicantId, userId)
                            .last("LIMIT 1")
            );
            if (myApply != null) {
                hasApplied = true;
                applyStatus = myApply.getStatus();
                myApplyId = myApply.getId();
            }
        }

        // 组装PostDetailVO
        PostDetailVO detailVO = new PostDetailVO();
        detailVO.setId(post.getId());
        detailVO.setTitle(post.getTitle());
        detailVO.setCategory(post.getCategory());
        detailVO.setTagIds(post.getTagIds());
        detailVO.setStartTime(post.getStartTime());
        detailVO.setEndTime(post.getEndTime());
        detailVO.setLocation(post.getLocation());
        detailVO.setMaxPeople(post.getMaxPeople());
        detailVO.setCurrentPeople(post.getCurrentPeople());
        detailVO.setStatus(post.getStatus());
        detailVO.setViewCount(post.getViewCount());
        detailVO.setPublisherId(post.getPublisherId());
        detailVO.setCreatedTime(post.getCreatedTime());
        detailVO.setRequireLevel(post.getRequireLevel());
        detailVO.setRequireGender(post.getRequireGender());
        detailVO.setDescription(post.getDescription());
        detailVO.setIsAuditPass(post.getIsAuditPass());
        detailVO.setApplyUsers(applyUsers);
        detailVO.setHasApplied(hasApplied);
        detailVO.setApplyStatus(applyStatus);
        detailVO.setMyApplyId(myApplyId);

        if (publisher != null) {
            detailVO.setPublisherNickname(publisher.getNickname());
            detailVO.setPublisherAvatar(publisher.getAvatar());
            detailVO.setPublisherCreditLevel(creditService.getCreditLevel(publisher.getCreditScore()));
            detailVO.setPublisherSignature(publisher.getSignature());
            detailVO.setPublisherCollege(publisher.getCollege());

            // 查询发布者的兴趣标签
            List<UserTag> publisherUserTags = userTagMapper.selectList(
                    new LambdaQueryWrapper<UserTag>().eq(UserTag::getUserId, publisher.getId())
            );
            List<PostDetailVO.PublisherTagVO> publisherTags = new ArrayList<>();
            for (UserTag ut : publisherUserTags) {
                InterestTag tag = interestTagMapper.selectById(ut.getTagId());
                if (tag != null && tag.getStatus() == 1) {
                    PostDetailVO.PublisherTagVO tagVO = new PostDetailVO.PublisherTagVO();
                    tagVO.setTagId(tag.getId());
                    tagVO.setTagName(tag.getName());
                    tagVO.setCategory(tag.getCategory());
                    tagVO.setSelfLevel(ut.getSelfLevel());
                    publisherTags.add(tagVO);
                }
            }
            detailVO.setPublisherTags(publisherTags);
        }

        return detailVO;
    }

    @Override
    public IPage<PostVO> getPostList(int page, int size, String category, String sort) {
        LambdaQueryWrapper<Post> wrapper = new LambdaQueryWrapper<Post>()
                .ne(Post::getStatus, PostStatus.CANCELLED);

        if (StrUtil.isNotBlank(category)) {
            wrapper.eq(Post::getCategory, category);
        }

        // 排序方式
        if ("hot".equals(sort)) {
            wrapper.orderByDesc(Post::getViewCount);
        } else {
            // 默认按时间倒序
            wrapper.orderByDesc(Post::getCreatedTime);
        }

        IPage<Post> postPage = postMapper.selectPage(new Page<>(page, size), wrapper);

        // 转换为PostVO
        IPage<PostVO> voPage = new Page<>(postPage.getCurrent(), postPage.getSize(), postPage.getTotal());
        voPage.setRecords(postPage.getRecords().stream()
                .map(this::convertToPostVO)
                .collect(Collectors.toList()));
        return voPage;
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void cancelPost(Long userId, Long postId) {
        Post post = postMapper.selectById(postId);
        if (post == null) {
            throw new BusinessException(ResultCode.NOT_FOUND, "帖子不存在");
        }

        // 校验是发布者
        if (!post.getPublisherId().equals(userId)) {
            throw new BusinessException(ResultCode.FORBIDDEN, "只能取消自己发布的帖子");
        }

        // 状态机校验
        PostStateMachine.checkTransition(post.getStatus(), PostStatus.CANCELLED);

        // 更新状态
        post.setStatus(PostStatus.CANCELLED);
        postMapper.updateById(post);
    }

    @Override
    public void incrementViewCount(Long postId, Long userId) {
        // Redis去重：10分钟内同一用户只计一次
        String key = VIEW_COUNT_KEY + postId + ":" + userId;
        Boolean isNew = redisTemplate.opsForValue().setIfAbsent(key, "1", VIEW_DEDUP_MINUTES, TimeUnit.MINUTES);
        if (Boolean.TRUE.equals(isNew)) {
            // 浏览量+1
            Post post = postMapper.selectById(postId);
            if (post != null) {
                post.setViewCount(post.getViewCount() + 1);
                postMapper.updateById(post);
            }
        }
    }

    /**
     * 将Post实体转换为PostVO
     */
    private PostVO convertToPostVO(Post post) {
        PostVO vo = new PostVO();
        vo.setId(post.getId());
        vo.setTitle(post.getTitle());
        vo.setCategory(post.getCategory());
        vo.setTagIds(post.getTagIds());
        vo.setStartTime(post.getStartTime());
        vo.setEndTime(post.getEndTime());
        vo.setLocation(post.getLocation());
        vo.setMaxPeople(post.getMaxPeople());
        vo.setCurrentPeople(post.getCurrentPeople());
        vo.setStatus(post.getStatus());
        vo.setViewCount(post.getViewCount());
        vo.setPublisherId(post.getPublisherId());
        vo.setCreatedTime(post.getCreatedTime());
        vo.setDescription(post.getDescription());

        // 根据tagIds查询标签名称
        if (StrUtil.isNotBlank(post.getTagIds())) {
            List<String> names = new ArrayList<>();
            for (String idStr : post.getTagIds().split(",")) {
                try {
                    Long tagId = Long.valueOf(idStr.trim());
                    InterestTag tag = interestTagMapper.selectById(tagId);
                    if (tag != null) {
                        names.add(tag.getName());
                    }
                } catch (NumberFormatException ignored) {
                }
            }
            vo.setTagName(String.join(",", names));
        }

        // 查询发布者信息
        User publisher = userMapper.selectById(post.getPublisherId());
        if (publisher != null) {
            vo.setPublisherNickname(publisher.getNickname());
            vo.setPublisherAvatar(publisher.getAvatar());
            vo.setPublisherCreditLevel(creditService.getCreditLevel(publisher.getCreditScore()));
        }
        return vo;
    }
}
```

### 解释

#### createPost() 方法

1. **校验信誉分**：信誉分过低（低于 60 分）的用户不能发布帖子，防止恶意发帖。
2. **校验同时进行中帖子数**：每个用户最多同时有 5 个进行中的帖子（RECRUITING/FULL/ONGOING），防止刷屏。
3. `currentPeople` 设为 1：发布者自己算 1 人。
4. `isAuditPass` 设为 0：新帖子默认待审核。
5. `status` 设为 `RECRUITING`：新帖子默认招募中。

#### getPostDetail() 方法

1. 查询帖子基本信息。
2. 查询发布者信息（昵称、头像、信誉、学院、签名、兴趣标签）。
3. 查询已报名用户列表（APPROVED 和 PENDING 状态），组装 `ApplyUserVO`。
4. 判断当前用户是否已报名：查询 `post_apply` 表中 `post_id = postId AND applicant_id = userId` 的记录。
5. 组装 `PostDetailVO`：手动设置每个字段（因为 PostDetailVO 继承 PostVO，不能用 BeanUtils 直接拷贝）。

**为什么 userId 可以为 null？** 因为帖子详情页不需要登录也能查看（在 `WebMvcConfig` 中排除了 `/api/post/detail/**`），未登录用户看不到报名状态。

#### getPostList() 方法

1. 排除已取消的帖子（`ne(Post::getStatus, PostStatus.CANCELLED)`）。
2. 可选按分类筛选。
3. 排序方式：`"hot"` 按浏览量降序，其他按创建时间降序。
4. 分页查询后转换为 PostVO。

#### cancelPost() 方法

1. 校验是帖子发布者。
2. **状态机校验**：调用 `PostStateMachine.checkTransition()`，如果当前状态不允许转为 CANCELLED，抛出异常。比如 FINISHED 状态的帖子不能再取消。
3. 更新状态为 CANCELLED。

#### incrementViewCount() 方法

1. **Redis 去重**：用 `setIfAbsent()` 设置 key `post:view:{postId}:{userId}`，如果 key 不存在则设置成功并返回 true，如果已存在则返回 false。
2. 设置过期时间 10 分钟：10 分钟后 key 自动删除，同一用户再次浏览会重新计数。
3. 只有设置成功时（`isNew == true`）才将浏览量 +1。
4. 这种方式比"先查再设"更高效，因为 `setIfAbsent` 是原子操作，不存在并发问题。

#### convertToPostVO() 方法

1. 将 Post 实体的基本字段复制到 PostVO。
2. 根据 `tagIds` 字符串（如 `"1,3,5"`）逐个查询标签名称，拼接为 `"篮球,王者荣耀"`。
3. 查询发布者信息，填充昵称、头像、信誉星级。

### 写入代码

```java
package com.buddy.service.impl;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.core.metadata.IPage;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.buddy.dto.response.CommentVO;
import com.buddy.entity.PostComment;
import com.buddy.entity.User;
import com.buddy.mapper.PostCommentMapper;
import com.buddy.mapper.UserMapper;
import com.buddy.service.CommentService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

import java.util.List;
import java.util.stream.Collectors;

/**
 * 评论服务实现类
 */
@Service
public class CommentServiceImpl implements CommentService {

    @Autowired
    private PostCommentMapper postCommentMapper;

    @Autowired
    private UserMapper userMapper;

    @Override
    public void addComment(Long userId, Long postId, String content) {
        PostComment comment = new PostComment();
        comment.setPostId(postId);
        comment.setUserId(userId);
        comment.setContent(content);
        postCommentMapper.insert(comment);
    }

    @Override
    public IPage<CommentVO> getComments(Long postId, int page, int size) {
        IPage<PostComment> commentPage = postCommentMapper.selectPage(
                new Page<>(page, size),
                new LambdaQueryWrapper<PostComment>()
                        .eq(PostComment::getPostId, postId)
                        .orderByDesc(PostComment::getCreatedTime)
        );

        // 转换为CommentVO并填充用户信息
        IPage<CommentVO> voPage = new Page<>(commentPage.getCurrent(), commentPage.getSize(), commentPage.getTotal());
        voPage.setRecords(commentPage.getRecords().stream().map(c -> {
            CommentVO vo = new CommentVO();
            vo.setId(c.getId());
            vo.setPostId(c.getPostId());
            vo.setUserId(c.getUserId());
            vo.setContent(c.getContent());
            vo.setCreatedTime(c.getCreatedTime());

            // 查询评论者信息
            User user = userMapper.selectById(c.getUserId());
            if (user != null) {
                vo.setNickname(user.getNickname());
                vo.setAvatar(user.getAvatar());
            }
            return vo;
        }).collect(Collectors.toList()));
        return voPage;
    }
}
```

### 解释

#### addComment() 方法

1. 创建 `PostComment` 实体，设置帖子 ID、用户 ID、评论内容。
2. 调用 `postCommentMapper.insert()` 插入数据库。`createdTime` 由 MyBatis-Plus 自动填充。

#### getComments() 方法

1. 分页查询指定帖子的评论，按创建时间倒序（最新的在前）。
2. 将 `PostComment` 实体转换为 `CommentVO`，同时查询评论者的昵称和头像。
3. **为什么不在 PostComment 表中存昵称和头像？** 因为用户的昵称和头像可能会修改，如果冗余存储，修改后评论中的信息就不一致了。关联查询虽然多一次 SQL，但保证数据一致性。

## 第十步：创建 PostController

### 创建文件

`backend/src/main/java/com/buddy/controller/user/PostController.java`

### 写入代码

```java
package com.buddy.controller.user;

import com.baomidou.mybatisplus.core.metadata.IPage;
import com.buddy.common.context.UserContext;
import com.buddy.common.result.R;
import com.buddy.dto.request.PostCreateRequest;
import com.buddy.dto.response.CommentVO;
import com.buddy.dto.response.PostDetailVO;
import com.buddy.service.CommentService;
import com.buddy.service.PostService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

import javax.validation.Valid;
import java.util.Map;

/**
 * 帖子控制器
 */
@RestController
@RequestMapping("/api/post")
public class PostController {

    @Autowired
    private PostService postService;

    @Autowired
    private CommentService commentService;

    /**
     * 发布组局
     */
    @PostMapping("/create")
    public R<Long> createPost(@RequestBody @Valid PostCreateRequest request) {
        Long userId = UserContext.getUserId();
        return R.ok(postService.createPost(userId, request));
    }

    /**
     * 帖子详情
     */
    @GetMapping("/detail/{id}")
    public R<PostDetailVO> getDetail(@PathVariable Long id) {
        Long userId = UserContext.getUserId();
        return R.ok(postService.getPostDetail(userId, id));
    }

    /**
     * 取消组局
     */
    @PostMapping("/cancel/{id}")
    public R<Void> cancelPost(@PathVariable Long id) {
        Long userId = UserContext.getUserId();
        postService.cancelPost(userId, id);
        return R.ok();
    }

    /**
     * 发表评论
     * body: {postId: 1, content: "xxx"}
     */
    @PostMapping("/comment")
    public R<Void> addComment(@RequestBody Map<String, Object> body) {
        Long userId = UserContext.getUserId();
        Long postId = Long.valueOf(body.get("postId").toString());
        String content = (String) body.get("content");
        commentService.addComment(userId, postId, content);
        return R.ok();
    }

    /**
     * 评论列表
     */
    @GetMapping("/comments/{postId}")
    public R<IPage<CommentVO>> getComments(
            @PathVariable Long postId,
            @RequestParam(defaultValue = "1") int page,
            @RequestParam(defaultValue = "10") int size) {
        return R.ok(commentService.getComments(postId, page, size));
    }
}
```

### 解释

- `@PathVariable`：从 URL 路径中取参数。比如 `/api/post/detail/123` 中的 `123` 就是 `id` 的值。
- `createPost`：需要登录，从 `UserContext` 获取 userId。
- `getDetail`：在 `WebMvcConfig` 中排除了 JWT 拦截，未登录也能访问。但 `UserContext.getUserId()` 在未登录时返回 null，Service 层会处理这种情况。
- `addComment`：接收 `Map<String, Object>` 而不是 DTO，因为只有两个字段，用 Map 更简洁。
- `getComments`：评论列表也不需要登录（在 `WebMvcConfig` 中排除了 `/api/post/comments/**`）。
