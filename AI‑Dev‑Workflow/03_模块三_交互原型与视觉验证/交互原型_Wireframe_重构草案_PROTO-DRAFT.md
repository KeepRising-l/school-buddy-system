# 2. 用户端 H5 页面 Wireframe

## 2.1 登录 /login

```text
┌─────────────────────┐
│      校园搭子        │
│  [用户名________]    │
│  [密码__________]    │
│  [    登录      ]    │  → 成功: 跳 /square（或 redirect 参数）
│  没有账号？去注册     │  → /register
└─────────────────────┘
```
交互：登录失败 toast 提示（账号密码错误/被封禁）；成功写 localStorage(h5_token)。

## 2.2 注册 /register

```text
┌─────────────────────┐
│  [学号__________]    │
│  [用户名________]    │
│  [手机号________]    │
│  [昵称__________]    │
│  [密码__________]    │
│  [确认密码______]    │
│  [    注册      ]    │  → 成功: 跳 /login
└─────────────────────┘
```
交互：学号/用户名/手机号唯一性校验失败 → 后端错误信息 toast。

## 2.3 广场 /square（默认首页，含 Tabbar）

```text
┌─────────────────────┐
│ 校园搭子      [🔔]   │ ← 未读角标, 点击→/message
│ [推荐][最新][最热]   │ ← 排序切换
│ [分类▾][时间▾][搜索] │ ← 筛选（今天/本周/本月）
│ ┌─────────────────┐ │
│ │ 篮球局 周六 3/5人 │ │ ← PostCard: 标题/分类Tag/时间/地点/人数/信誉星
│ └─────────────────┘ │
│ ┌─────────────────┐ │
│ │ 剧本杀 今晚 4/6人 │ │
│ └─────────────────┘ │
│        [ + ]        │ ← 右下角悬浮, 点击→/post/create(需登录)
│ [广场] [消息] [我的] │ ← Tabbar
└─────────────────────┘
```
交互：下拉刷新/上拉加载；空状态 EmptyState；游客可浏览，点「+」未登录→/login。

## 2.4 发布组局 /post/create

```text
┌─────────────────────┐
│ ← 发布组局           │
│ [标题____________]   │
│ [分类▾]  [标签多选]  │
│ [开始时间⌚][结束时间]│
│ [地点__________]    │

```
交互：时间选择器；标签多选（按分类分组）；校验失败标红提示。

## 2.5 组局详情 /post/:id

```text
┌─────────────────────┐
│ ← 组局详情      [分享]│
│ 篮球局               │
│ 发布者: [头像]小明 ★92│ ← 点击→/user/:userId
│ 时间/地点/人数(3/5)   │
│ [ Tag: 篮球 ]        │
│ 描述正文……           │
│ ── 评论(2) ──        │
│ 小红: 带我一个！      │
│ [我也要说____][发送]  │
│ ────────────────    │
│ [☆收藏][我要报名]    │ ← 底部操作栏
└─────────────────────┘
```
交互（按角色/状态变化）：
- 游客：点报名→/login；
- 普通用户：RECRUITING→「我要报名」；FULL→「我要候补」；已报名→「取消报名」；资格不足/信誉低→ 后端错误 toast（含原因）；
- 发布者：「管理报名」入口→ 收到的申请（审批/出勤标记）；非终态→「取消组局」；
- FINISHED 且是参与者 →「去评价」→ /review/:postId。

# 4. 核心交互流程（端到端）

1. **发局→报名→审批**：发布者发局（先发后审，广场立即可见）→ 用户 A 报名（toast 校验结果）→ 发布者收通知 → 我的发布/报名管理 → 通过 → A 收通知，人数+1；
2. **满员→候补→递补**：审批至满员 → 帖转「已满」→ 用户 B 报名自动候补（通知第 N 位）→ A 取消报名 → B 自动递补为待审核 + 双方收通知；
3. **出勤→评价→信誉**：定时任务推进 ONGOING/FINISHED → 发布者标记出勤 → NOSHOW 即时扣 10 分并发通知 → 参与者互评（星级+标签）→ 信誉分重算 → 广场推荐排序反映信誉。
