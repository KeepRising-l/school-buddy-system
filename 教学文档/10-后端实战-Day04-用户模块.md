- 使用 JWT 生成和验证 Token

## 第一步：创建 LoginRequest DTO

### 创建文件

`backend/src/main/java/com/buddy/dto/request/LoginRequest.java`

### 写入代码

```java
package com.buddy.dto.request;

import lombok.Data;

import javax.validation.constraints.NotBlank;

/**
 * 登录请求
 */
@Data
public class LoginRequest {

    @NotBlank(message = "账号不能为空")
    private String account;  // 学号或手机号

    @NotBlank(message = "密码不能为空")
    private String password;
}
```

### 解释

- `@Data`：Lombok 注解，自动生成 getter、setter、toString 等方法，不用手写。
- `@NotBlank`：参数校验注解，表示该字段不能为空字符串或 null。配合 Controller 中的 `@Valid` 注解使用，校验不通过时 Spring 会自动返回 400 错误。
- `account` 字段：登录时可以用学号或手机号，统一用一个字段接收，后端用 `OR` 条件查询。
- `password` 字段：前端传明文密码，后端用 BCrypt 校验。

## 第二步：创建 RegisterRequest DTO

### 创建文件

`backend/src/main/java/com/buddy/dto/request/RegisterRequest.java`

### 写入代码

```java
package com.buddy.dto.request;

import lombok.Data;

import javax.validation.constraints.NotBlank;
import javax.validation.constraints.Pattern;

/**
 * 注册请求
 */
@Data
public class RegisterRequest {

    /** 注册方式：student学号注册 phone手机号注册 */
    private String registerType;

    /** 学号（学号注册时必填，手机号注册时选填） */
    @Pattern(regexp = "\\d{8,12}", message = "学号格式不正确")
    private String studentNo;

    /** 手机号（手机号注册时必填，学号注册时选填） */
    @Pattern(regexp = "1[3-9]\\d{9}", message = "手机号格式不正确")
    private String phone;

    @NotBlank(message = "密码不能为空")
    @Pattern(regexp = "^(?=.*[A-Za-z])(?=.*\\d)[A-Za-z\\d@$!%*#?&]{8,20}$", message = "密码需8-20位，包含字母和数字")
    private String password;

    @NotBlank(message = "姓名不能为空")
    private String realName;
}
```

### 解释

- `registerType`：区分注册方式。值为 `student` 表示学号注册，值为 `phone` 表示手机号注册。后端根据这个值决定哪个字段是必填的。
- `@Pattern(regexp = "\\d{8,12}")`：学号必须是 8-12 位纯数字。
- `@Pattern(regexp = "1[3-9]\\d{9}")`：手机号必须是 1 开头、第二位 3-9、共 11 位的数字。
- `@Pattern(regexp = "^(?=.*[A-Za-z])(?=.*\\d)...")`：密码必须 8-20 位，同时包含字母和数字，增强安全性。
- `@NotBlank` 和 `@Pattern` 可以同时使用，先校验非空，再校验格式。
- 注意：`studentNo` 和 `phone` 没有加 `@NotBlank`，因为它们不是同时必填的，具体哪个必填由后端业务逻辑判断。

## 第三步：创建 ProfileUpdateRequest DTO

### 创建文件

`backend/src/main/java/com/buddy/dto/request/ProfileUpdateRequest.java`

### 写入代码

```java
package com.buddy.dto.request;

import lombok.Data;

import javax.validation.constraints.Size;

/**
 * 个人信息更新请求
 */
@Data
public class ProfileUpdateRequest {

    @Size(min = 2, max = 20, message = "昵称2-20字符")
    private String nickname;

    private String avatar;

    @Size(max = 100, message = "签名最长100字符")
    private String signature;

    private String college;

    /** 性别：0未知 1男 2女 */
    private Integer gender;
}
```

### 解释

- `@Size(min = 2, max = 20)`：昵称长度限制 2-20 个字符。
- `@Size(max = 100)`：个性签名最长 100 个字符。
- 所有字段都没有加 `@NotBlank`，因为更新个人资料时，用户可能只修改其中某几个字段，其他字段不传。后端会判断：传了就更新，没传就保持原值。
- `avatar`：头像 URL 字符串，前端上传图片后拿到 URL，再传给这个接口保存。
- `gender`：0 表示未知/未设置，1 表示男，2 表示女。

## 第四步：创建 UserVO

### 创建文件

`backend/src/main/java/com/buddy/dto/response/UserVO.java`

### 写入代码

```java
package com.buddy.dto.response;

import lombok.Data;

import java.time.LocalDateTime;

/**
 * 用户视图对象（不含密码）
 */
@Data
public class UserVO {

    private Long id;

    private String studentNo;

    private String phone;

    private String nickname;

    private String avatar;

    private String signature;

    private String college;

    private Integer gender;

    private Integer creditScore;

    /** 计算后的星级 1-5 */
    private Integer creditLevel;

    /** 信誉标签：靠谱队友/优质队友/... */
    private String creditLabel;

    private Integer status;

    private LocalDateTime createdTime;
}
```

### 解释

- **为什么需要 VO？** User 实体包含 `password` 字段，如果直接返回 Entity 给前端，密码就会泄露。VO 只包含需要展示的字段，是一种安全措施。
- `creditLevel` 和 `creditLabel`：数据库中只存了 `creditScore`（信誉分），星级和标签文字是根据分数计算出来的，不是数据库字段。计算逻辑在 `CreditService` 中。
- `status`：1 表示正常，0 表示封禁。前端可以根据这个值决定是否显示"账号异常"提示。
- `createdTime`：注册时间，前端可以显示"已加入 XX 天"。

## 第五步：创建 UserService 接口

### 创建文件

`backend/src/main/java/com/buddy/service/UserService.java`

### 写入代码

```java
package com.buddy.service;

import com.baomidou.mybatisplus.core.metadata.IPage;
import com.buddy.dto.request.LoginRequest;
import com.buddy.dto.request.ProfileUpdateRequest;
import com.buddy.dto.request.RegisterRequest;
import com.buddy.dto.response.PostVO;
import com.buddy.dto.response.UserVO;
import com.buddy.dto.response.UserTagVO;
import com.buddy.entity.PostApply;

import java.util.List;

/**
 * 用户服务接口
 */
public interface UserService {

    /**
     * 用户注册
     */
    void register(RegisterRequest request);

    /**
     * 用户登录，返回JWT Token
     */
    String login(LoginRequest request);

    /**
     * 获取用户个人信息
     */
    UserVO getProfile(Long userId);

    /**
     * 更新用户个人信息
     */
    void updateProfile(Long userId, ProfileUpdateRequest request);

    /**
     * 获取用户的兴趣标签列表
     */
    List<UserTagVO> getUserTags(Long userId);

    /**
     * 设置用户的兴趣标签（全量替换）
     */
    void setUserTags(Long userId, List<Long> tagIds, List<Integer> levels);

    /**
     * 获取我发布的帖子列表
     */
    IPage<PostVO> getMyPosts(Long userId, int page, int size, String status);

    /**
     * 获取我的报名记录
     */
    IPage<PostApply> getMyApplies(Long userId, int page, int size, String status);
}
```

### 解释

- 接口只定义方法签名，具体实现在 `UserServiceImpl` 中。这是**面向接口编程**的思想，好处是 Controller 只依赖接口，不依赖具体实现，方便后续替换实现类。
- `register`：注册不需要返回值，成功就成功，失败抛异常。
- `login`：返回 JWT Token 字符串。Controller 拿到 Token 后，再调用 `getProfile` 获取用户信息，一起返回给前端。
- `getProfile`：返回 `UserVO` 而不是 `User`，避免泄露密码。
- `setUserTags`：`tagIds` 和 `levels` 是两个列表，一一对应。比如 `tagIds=[1,2,3]`，`levels=[3,2,5]` 表示标签1段位3、标签2段位2、标签3段位5。采用"先删后插"策略，即先删除该用户所有标签关联，再批量插入新的。
- `getMyPosts` 和 `getMyApplies`：返回 `IPage` 分页对象，包含当前页数据、总条数、总页数等信息。

## 第六步：创建 UserServiceImpl 实现类

### 创建文件

`backend/src/main/java/com/buddy/service/impl/UserServiceImpl.java`

### 写入代码

```java
package com.buddy.service.impl;

import cn.hutool.core.util.StrUtil;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.core.metadata.IPage;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.buddy.common.constant.ApplyStatus;
import com.buddy.common.constant.CreditConstant;
import com.buddy.common.constant.PostStatus;
import com.buddy.common.exception.BusinessException;
import com.buddy.common.jwt.JwtUtils;
import com.buddy.common.result.ResultCode;
import com.buddy.dto.request.LoginRequest;
import com.buddy.dto.request.ProfileUpdateRequest;
import com.buddy.dto.request.RegisterRequest;
import com.buddy.dto.response.PostVO;
import com.buddy.dto.response.UserTagVO;
import com.buddy.dto.response.UserVO;
import com.buddy.entity.InterestTag;
import com.buddy.entity.Post;
import com.buddy.entity.PostApply;
import com.buddy.entity.User;
import com.buddy.entity.UserTag;
import com.buddy.mapper.InterestTagMapper;
import com.buddy.mapper.PostApplyMapper;
import com.buddy.mapper.PostMapper;
import com.buddy.mapper.UserMapper;
import com.buddy.mapper.UserTagMapper;
import com.buddy.service.CreditService;
import com.buddy.service.UserService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import org.springframework.data.redis.core.StringRedisTemplate;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.concurrent.TimeUnit;
import java.util.stream.Collectors;

/**
 * 用户服务实现类
 */
@Service
public class UserServiceImpl implements UserService {

    @Autowired
    private UserMapper userMapper;

    @Autowired
    private UserTagMapper userTagMapper;

    @Autowired
    private InterestTagMapper interestTagMapper;

    @Autowired
    private PostMapper postMapper;

    @Autowired
    private PostApplyMapper postApplyMapper;

    @Autowired
    private CreditService creditService;

    @Autowired
    private JwtUtils jwtUtils;

    @Autowired
    private StringRedisTemplate redisTemplate;

    private final BCryptPasswordEncoder passwordEncoder = new BCryptPasswordEncoder();

    /** 登录失败计数缓存前缀 */
    private static final String LOGIN_FAIL_KEY = "login:fail:";
    /** 最大登录失败次数 */
    private static final int MAX_LOGIN_FAIL = 5;
    /** 锁定时间（分钟） */
    private static final int LOCK_MINUTES = 30;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void register(RegisterRequest request) {
        boolean isPhoneRegister = "phone".equals(request.getRegisterType());

        if (isPhoneRegister) {
            // 手机号注册：手机号必填
            if (StrUtil.isBlank(request.getPhone())) {
                throw new BusinessException("手机号不能为空");
            }
            // 校验手机号是否已存在
            Long countByPhone = userMapper.selectCount(
                    new LambdaQueryWrapper<User>().eq(User::getPhone, request.getPhone())
            );
            if (countByPhone > 0) {
                throw new BusinessException(ResultCode.USER_EXISTS, "该手机号已注册");
            }
            // 学号选填，如果填了也校验唯一性
            if (StrUtil.isNotBlank(request.getStudentNo())) {
                Long countByStudentNo = userMapper.selectCount(
                        new LambdaQueryWrapper<User>().eq(User::getStudentNo, request.getStudentNo())
                );
                if (countByStudentNo > 0) {
                    throw new BusinessException(ResultCode.USER_EXISTS, "该学号已注册");
                }
            }
        } else {
            // 学号注册：学号必填
            if (StrUtil.isBlank(request.getStudentNo())) {
                throw new BusinessException("学号不能为空");
            }
            // 校验学号是否已存在
            Long countByStudentNo = userMapper.selectCount(
                    new LambdaQueryWrapper<User>().eq(User::getStudentNo, request.getStudentNo())
            );
            if (countByStudentNo > 0) {
                throw new BusinessException(ResultCode.USER_EXISTS, "该学号已注册");
            }
            // 手机号选填，如果填了也校验唯一性
            if (StrUtil.isNotBlank(request.getPhone())) {
                Long countByPhone = userMapper.selectCount(
                        new LambdaQueryWrapper<User>().eq(User::getPhone, request.getPhone())
                );
                if (countByPhone > 0) {
                    throw new BusinessException(ResultCode.USER_EXISTS, "该手机号已注册");
                }
            }
        }

        // 构建用户实体
        User user = new User();
        user.setStudentNo(request.getStudentNo());
        user.setPhone(request.getPhone());
        // BCrypt加密密码
        user.setPassword(passwordEncoder.encode(request.getPassword()));
        user.setNickname(request.getRealName());
        user.setCreditScore(CreditConstant.INITIAL_SCORE);
        user.setStatus(1);
        user.setIsAdmin(0);
        user.setGender(0);

        userMapper.insert(user);
    }

    @Override
    public String login(LoginRequest request) {
        // 检查账号是否被锁定
        String lockKey = LOGIN_FAIL_KEY + request.getAccount();
        String failCountStr = redisTemplate.opsForValue().get(lockKey);
        if (failCountStr != null && Integer.parseInt(failCountStr) >= MAX_LOGIN_FAIL) {
            throw new BusinessException("登录失败次数过多，账号已锁定" + LOCK_MINUTES + "分钟，请稍后再试");
        }

        // 根据学号或手机号查询用户
        User user = userMapper.selectOne(
                new LambdaQueryWrapper<User>()
                        .eq(User::getStudentNo, request.getAccount())
                        .or()
                        .eq(User::getPhone, request.getAccount())
        );
        if (user == null) {
            incrementLoginFail(lockKey);
            throw new BusinessException(ResultCode.USER_NOT_FOUND);
        }

        // 校验用户是否被封禁
        if (user.getStatus() == 0) {
            throw new BusinessException(ResultCode.FORBIDDEN, "账号已被封禁");
        }

        // BCrypt校验密码
        if (!passwordEncoder.matches(request.getPassword(), user.getPassword())) {
            incrementLoginFail(lockKey);
            throw new BusinessException(ResultCode.PASSWORD_ERROR);
        }

        // 登录成功，清除失败计数
        redisTemplate.delete(lockKey);

        // 生成JWT Token
        return jwtUtils.generateToken(user.getId(), user.getStudentNo());
    }

    /**
     * 增加登录失败计数
     */
    private void incrementLoginFail(String lockKey) {
        Long count = redisTemplate.opsForValue().increment(lockKey);
        if (count != null && count == 1) {
            // 第一次失败，设置过期时间
            redisTemplate.expire(lockKey, LOCK_MINUTES, TimeUnit.MINUTES);
        }
    }

    @Override
    public UserVO getProfile(Long userId) {
        User user = userMapper.selectById(userId);
        if (user == null) {
            throw new BusinessException(ResultCode.USER_NOT_FOUND);
        }
        return convertToUserVO(user);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void updateProfile(Long userId, ProfileUpdateRequest request) {
        User user = userMapper.selectById(userId);
        if (user == null) {
            throw new BusinessException(ResultCode.USER_NOT_FOUND);
        }

        // 更新非空字段
        if (StrUtil.isNotBlank(request.getNickname())) {
            user.setNickname(request.getNickname());
        }
        if (StrUtil.isNotBlank(request.getAvatar())) {
            user.setAvatar(request.getAvatar());
        }
        if (request.getSignature() != null) {
            user.setSignature(request.getSignature());
        }
        if (StrUtil.isNotBlank(request.getCollege())) {
            user.setCollege(request.getCollege());
        }
        if (request.getGender() != null) {
            user.setGender(request.getGender());
        }

        userMapper.updateById(user);
    }

    @Override
    public List<UserTagVO> getUserTags(Long userId) {
        // 查询用户的标签关联
        List<UserTag> userTags = userTagMapper.selectList(
                new LambdaQueryWrapper<UserTag>().eq(UserTag::getUserId, userId)
        );
        if (userTags.isEmpty()) {
            return new ArrayList<>();
        }

        // 构建 tagId -> selfLevel 映射
        Map<Long, Integer> levelMap = userTags.stream()
                .collect(Collectors.toMap(UserTag::getTagId, UserTag::getSelfLevel, (a, b) -> a));

        // 查询标签详情，组装为 UserTagVO
        List<InterestTag> tags = interestTagMapper.selectBatchIds(levelMap.keySet());
        return tags.stream().map(tag -> {
            UserTagVO vo = new UserTagVO();
            vo.setId(tag.getId());
            vo.setCategory(tag.getCategory());
            vo.setName(tag.getName());
            vo.setDescription(tag.getDescription());
            vo.setSortOrder(tag.getSortOrder());
            vo.setSelfLevel(levelMap.getOrDefault(tag.getId(), 1));
            return vo;
        }).collect(Collectors.toList());
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void setUserTags(Long userId, List<Long> tagIds, List<Integer> levels) {
        // 先删除旧的关联
        userTagMapper.delete(
                new LambdaQueryWrapper<UserTag>().eq(UserTag::getUserId, userId)
        );

        // 批量插入新关联
        for (int i = 0; i < tagIds.size(); i++) {
            UserTag userTag = new UserTag();
            userTag.setUserId(userId);
            userTag.setTagId(tagIds.get(i));
            userTag.setSelfLevel(levels.get(i));
            userTagMapper.insert(userTag);
        }
    }

    @Override
    public IPage<PostVO> getMyPosts(Long userId, int page, int size, String status) {
        LambdaQueryWrapper<Post> wrapper = new LambdaQueryWrapper<Post>()
                .eq(Post::getPublisherId, userId)
                .orderByDesc(Post::getCreatedTime);

        if (StrUtil.isNotBlank(status)) {
            wrapper.eq(Post::getStatus, status);
        }

        IPage<Post> postPage = postMapper.selectPage(new Page<>(page, size), wrapper);

        // 转换为PostVO
        IPage<PostVO> voPage = new Page<>(postPage.getCurrent(), postPage.getSize(), postPage.getTotal());
        voPage.setRecords(postPage.getRecords().stream()
                .map(this::convertToPostVO)
                .collect(Collectors.toList()));
        return voPage;
    }

    @Override
    public IPage<PostApply> getMyApplies(Long userId, int page, int size, String status) {
        LambdaQueryWrapper<PostApply> wrapper = new LambdaQueryWrapper<PostApply>()
                .eq(PostApply::getApplicantId, userId)
                .orderByDesc(PostApply::getApplyTime);

        if (StrUtil.isNotBlank(status)) {
            wrapper.eq(PostApply::getStatus, status);
        }

        return postApplyMapper.selectPage(new Page<>(page, size), wrapper);
    }

    /**
     * 将User实体转换为UserVO
     */
    private UserVO convertToUserVO(User user) {
        UserVO vo = new UserVO();
        vo.setId(user.getId());
        vo.setStudentNo(user.getStudentNo());
        vo.setPhone(user.getPhone());
        vo.setNickname(user.getNickname());
        vo.setAvatar(user.getAvatar());
        vo.setSignature(user.getSignature());
        vo.setCollege(user.getCollege());
        vo.setGender(user.getGender());
        vo.setCreditScore(user.getCreditScore());
        vo.setCreditLevel(creditService.getCreditLevel(user.getCreditScore()));
        vo.setCreditLabel(creditService.getCreditLabel(user.getCreditScore()));
        vo.setStatus(user.getStatus());
        vo.setCreatedTime(user.getCreatedTime());
        return vo;
    }

    /**
     * 将Post实体转换为PostVO（不含发布者信息）
     */
    private PostVO convertToPostVO(Post post) {
        PostVO vo = new PostVO();
        vo.setId(post.getId());
        vo.setTitle(post.getTitle());
        vo.setCategory(post.getCategory());
        vo.setTagIds(post.getTagIds());
        vo.setStartTime(post.getStartTime());
        vo.setEndTime(post.getEndTime());
        vo.setLocation(post.getLocation());
        vo.setMaxPeople(post.getMaxPeople());
        vo.setCurrentPeople(post.getCurrentPeople());
        vo.setStatus(post.getStatus());
        vo.setViewCount(post.getViewCount());
        vo.setPublisherId(post.getPublisherId());
        vo.setCreatedTime(post.getCreatedTime());

        // 查询发布者信息
        User publisher = userMapper.selectById(post.getPublisherId());
        if (publisher != null) {
            vo.setPublisherNickname(publisher.getNickname());
            vo.setPublisherAvatar(publisher.getAvatar());
            vo.setPublisherCreditLevel(creditService.getCreditLevel(publisher.getCreditScore()));
        }
        return vo;
    }
}
```

### 解释

#### register() 方法

1. 根据 `registerType` 判断注册方式：`phone` 为手机号注册，其他为学号注册。
2. 手机号注册时：手机号必填，学号选填。学号注册时反过来。
3. 使用 `StrUtil.isBlank()` 判断字符串是否为空（Hutool 工具类，比手写更简洁）。
4. 使用 `LambdaQueryWrapper` 构建查询条件，`eq` 表示等于，`selectCount` 返回满足条件的记录数。
5. 使用 `passwordEncoder.encode()` 对密码进行 BCrypt 加密。BCrypt 是一种自适应哈希算法，每次加密结果不同，安全性远高于 MD5。
6. 新用户初始信誉分为 100（`CreditConstant.INITIAL_SCORE`），状态为 1（正常），非管理员，性别未知。
7. `@Transactional`：事务注解，保证方法内所有数据库操作要么全部成功，要么全部回滚。

#### login() 方法

1. **Redis 登录失败计数**：用 `login:fail:账号` 作为 Redis 的 key，value 存失败次数。每次密码错误就 +1，达到 5 次就锁定 30 分钟。
2. `increment()`：Redis 的自增操作，返回自增后的值。第一次失败时 count=1，此时设置过期时间 30 分钟。
3. 查询用户时使用 `OR` 条件：学号等于 account **或者** 手机号等于 account。
4. `passwordEncoder.matches(明文, 密文)`：BCrypt 的密码校验方法，返回 true/false。
5. 登录成功后用 `redisTemplate.delete()` 清除失败计数。
6. 调用 `jwtUtils.generateToken()` 生成 JWT Token 返回。

#### getProfile() 方法

1. 根据 userId 查询用户。
2. 调用 `convertToUserVO()` 将 Entity 转为 VO。
3. `creditLevel` 和 `creditLabel` 由 `CreditService` 计算，不在数据库中存储。

#### updateProfile() 方法

1. 先查出用户，再逐个判断字段是否需要更新。
2. `StrUtil.isNotBlank()` 判断字符串非空且非纯空白。
3. `signature` 字段用 `!= null` 判断而不是 `isNotBlank`，因为用户可能想把签名清空（设为空字符串）。
4. `@Transactional`：更新操作加事务，保证数据一致性。

#### getUserTags() 方法

1. 先查 `user_tag` 表获取该用户关联的所有标签 ID 和段位。
2. 构建 `tagId -> selfLevel` 的 Map，方便后续查询。
3. 用 `selectBatchIds()` 批量查询标签详情，避免 N+1 查询问题。
4. 组装 `UserTagVO` 返回。

#### setUserTags() 方法

1. **先删后插**策略：先删除该用户所有标签关联，再逐条插入新的。简单可靠，避免复杂的 diff 逻辑。
2. `@Transactional`：删除和插入必须在同一事务中，保证原子性。

#### getMyPosts() 方法

1. 查询 `publisher_id = userId` 的帖子，按创建时间倒序。
2. 可选按 `status` 筛选（如只看"招募中"的帖子）。
3. 分页查询后，将 `Post` 实体转为 `PostVO`。

#### getMyApplies() 方法

1. 查询 `applicant_id = userId` 的报名记录，按申请时间倒序。
2. 可选按 `status` 筛选。

## 第七步：创建 AuthController

### 创建文件

`backend/src/main/java/com/buddy/controller/user/AuthController.java`

### 写入代码

```java
package com.buddy.controller.user;

import com.buddy.common.jwt.JwtUtils;
import com.buddy.common.result.R;
import com.buddy.dto.request.LoginRequest;
import com.buddy.dto.request.RegisterRequest;
import com.buddy.dto.response.UserVO;
import com.buddy.service.UserService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

import javax.validation.Valid;
import java.util.HashMap;
import java.util.Map;

/**
 * 认证控制器
 */
@RestController
@RequestMapping("/api/auth")
public class AuthController {

    @Autowired
    private UserService userService;

    @Autowired
    private JwtUtils jwtUtils;

    /**
     * 用户注册
     */
    @PostMapping("/register")
    public R<Void> register(@RequestBody @Valid RegisterRequest request) {
        userService.register(request);
        return R.ok();
    }

    /**
     * 用户登录，返回token和用户信息
     */
    @PostMapping("/login")
    public R<Map<String, Object>> login(@RequestBody @Valid LoginRequest request) {
        String token = userService.login(request);
        // 从token中解析userId（登录接口不走JWT拦截器，不能从UserContext取）
        Long userId = jwtUtils.getUserIdFromToken(token);
        UserVO userVO = userService.getProfile(userId);

        Map<String, Object> data = new HashMap<>();
        data.put("token", token);
        data.put("user", userVO);
        return R.ok(data);
    }
}
```

### 解释

- `@RestController`：标记这是一个 REST 控制器，方法返回值自动序列化为 JSON。
- `@RequestMapping("/api/auth")`：该控制器下所有接口的 URL 前缀为 `/api/auth`。
- `@RequestBody`：表示从请求体中读取参数（JSON 格式），而不是从 URL 参数中读取。
- `@Valid`：触发参数校验。如果 `LoginRequest` 中的 `@NotBlank` 校验不通过，Spring 会自动返回 400 错误。
- `register` 接口：注册成功返回 `R.ok()`，不携带数据。
- `login` 接口：登录成功后返回 `token` 和 `user` 信息。前端拿到 token 后存入 localStorage，后续请求在 Header 中携带 `Authorization: Bearer <token>`。
- **为什么登录接口要从 Token 解析 userId？** 因为登录接口不走 JWT 拦截器（在 `WebMvcConfig` 中排除了 `/api/auth/**`），所以 `UserContext.getUserId()` 拿不到值。只能从刚生成的 Token 中解析。

## 第八步：创建 UserController

### 创建文件

`backend/src/main/java/com/buddy/controller/user/UserController.java`

### 写入代码

```java
package com.buddy.controller.user;

import com.baomidou.mybatisplus.core.metadata.IPage;
import com.buddy.common.context.UserContext;
import com.buddy.common.result.R;
import com.buddy.dto.request.ProfileUpdateRequest;
import com.buddy.dto.response.PostVO;
import com.buddy.dto.response.UserTagVO;
import com.buddy.dto.response.UserVO;
import com.buddy.entity.PostApply;
import com.buddy.service.UserService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

import javax.validation.Valid;
import java.util.List;
import java.util.Map;

/**
 * 用户控制器
 */
@RestController
@RequestMapping("/api/user")
public class UserController {

    @Autowired
    private UserService userService;

    /**
     * 获取个人资料
     */
    @GetMapping("/profile")
    public R<UserVO> getProfile() {
        Long userId = UserContext.getUserId();
        return R.ok(userService.getProfile(userId));
    }

    /**
     * 编辑个人资料
     */
    @PutMapping("/profile")
    public R<Void> updateProfile(@RequestBody @Valid ProfileUpdateRequest request) {
        Long userId = UserContext.getUserId();
        userService.updateProfile(userId, request);
        return R.ok();
    }

    /**
     * 获取我的标签
     */
    @GetMapping("/tags")
    public R<List<UserTagVO>> getMyTags() {
        Long userId = UserContext.getUserId();
        return R.ok(userService.getUserTags(userId));
    }

    /**
     * 设置兴趣标签
     * body: {tagIds: [1,2,3], levels: [3,2,5]}
     */
    @PutMapping("/tags")
    public R<Void> setUserTags(@RequestBody Map<String, Object> body) {
        Long userId = UserContext.getUserId();
        @SuppressWarnings("unchecked")
        List<Long> tagIds = (List<Long>) body.get("tagIds");
        @SuppressWarnings("unchecked")
        List<Integer> levels = (List<Integer>) body.get("levels");
        userService.setUserTags(userId, tagIds, levels);
        return R.ok();
    }

    /**
     * 我的发布
     */
    @GetMapping("/posts")
    public R<IPage<PostVO>> getMyPosts(
            @RequestParam(defaultValue = "1") int page,
            @RequestParam(defaultValue = "10") int size,
            @RequestParam(required = false) String status) {
        Long userId = UserContext.getUserId();
        return R.ok(userService.getMyPosts(userId, page, size, status));
    }

    /**
     * 我的预约
     */
    @GetMapping("/applies")
    public R<IPage<PostApply>> getMyApplies(
            @RequestParam(defaultValue = "1") int page,
            @RequestParam(defaultValue = "10") int size,
            @RequestParam(required = false) String status) {
        Long userId = UserContext.getUserId();
        return R.ok(userService.getMyApplies(userId, page, size, status));
    }
}
```

### 解释

- `UserContext.getUserId()`：从 ThreadLocal 中获取当前登录用户 ID。这个值是 JWT 拦截器在请求进入 Controller 之前设置的。
- `@GetMapping` / `@PostMapping` / `@PutMapping`：分别对应 HTTP 的 GET、POST、PUT 方法。
- `@RequestParam`：从 URL 查询参数中读取值。`defaultValue` 设置默认值，`required = false` 表示参数可选。
- `setUserTags` 接口：接收 `Map<String, Object>` 而不是 DTO，因为 `tagIds` 和 `levels` 是两个数组，用 Map 接收更灵活。前端传 `{"tagIds": [1,2,3], "levels": [3,2,5]}`。
- `@SuppressWarnings("unchecked")`：抑制未检查的类型转换警告，因为从 Map 中取出的 Object 需要强转为 List。
